# 设计策略地图生成 Skill

## 适用场景
用于把输入材料转化为可评审的体验策略判断。

## 执行流程
1. 定界对象、场景、目标、边界与成功标准。
2. 按用户、竞品、业务、数据进行证据盘点。
3. 读取相关 methods、domain-pack 与 case-library。
4. 归纳问题、根因、策略层和设计动作。
5. 输出可验证指标、风险和待补材料。

## 质量自检
- 每个结论必须能追溯来源。
- 不把单个案例做法直接上升为通用原则。
- 缺数据时只给验证口径，不编造指标。
