## 一、人物角色描摹骨架（每个角色九模块）

固定开头一句话总览，再逐个角色描摹。

```
# 人物角色（研究目标：[一句话复述本次目标]）

本次基于 [N 份/位] 材料，采用 [定性 / 经定量验证的定性 / 定量] 人物角色创建方法，
按核心变量 **[核心变量 1（× 核心变量 2）]** 划分出 **[K]** 类典型用户。

---

## 角色 1：[角色类型名称——朗朗上口、可记忆，如「凑券型囤货妈妈」]

- **照片**：[占位 / 一句文字描述这类用户的形象气质]（真人照片需线下补用户书面授权，见运行说明）
- **基础信息**：[年龄/区间 · 性别 · 城市线级 · 职业 · 月收入区间或中位数 · 家庭状态 …均为该类代表值，非某真人]
- **特征标签**：[3–6 个体现本角色关键差异的标签，如「价格敏感↑」「囤货倾向↑」「促销规则钻研者」]
- **典型语录**："[一语道破核心诉求的提炼性表达（基于真实原话提炼、已匿名）]"
- **用户故事**：[家庭/生活状态/兴趣/消费渠道概况，几句话让人联想到真实的一类人]
- **使用行为**：[使用场景 · 使用动机 · 常用功能 · 行为模式 ——可对照同理心地图 Say/Do/Think/Feel 写立体]
- **需求及痛点**：
    - 表层痛点：[用户直接说出的不满]
    - 深层需求（结果→结论→洞察）：[痛点背后、场景里的真实需求——别停在表象]
- **核心建议**：[基于深层需求的可行动策略/产品或运营方向；若用养成透镜，点明对应阶段动作]
- **支撑证据（可回溯）**：来自 [用户A、用户D …]；代表原话："[原话]" —— [代称]

  > 标注：[本角色哪些模块基于 draft 正典 / 因证据偏薄而谨慎描摹，在此就地标一句]

## 角色 2：[…]
  …
```

写法约束：
- **每个模块都要能回溯到材料**：特征标签、语录、行为、比例都点得到出处（哪位用户），绝不为"丰满"虚构（SKILL.md 纪律 4）。
- **角色之间要足够不同**：若两个角色的核心变量取值雷同、只是辅助信息有别，说明没划分开，应合并或重选核心变量。
- **照片**永远用占位/描述，不插入任何未授权真人照片。
- **角色数量随数据浮现**，不硬凑整数；定性阶段每类用户通常 3–5 人支撑（不足则在运行说明声明样本单薄）。

```
## 用户划分依据

- **创建方法**：[定性 / 经定量验证的定性 / 定量]——[一句话说明为何选它（据现有数据）]
- **变量集合**：从材料中抽取的划分变量
    - 目标类：[…]
    - 行为类：[…（含生命周期/养成阶段，如适用）]
    - 观点类：[…]
    - 其他：[需求强度 / 价格敏感 / 品牌态度 …]
- **核心变量（1–2 个）**：[核心变量及为何是它]　**辅助变量**：[仅用于展示差异的变量]
- **（如用）手动归类**：[简述在哪几个变量轴上、哪些用户聚成一类]
- **（如适用）量化验证**：
    - 验证设计：[核心变量对应的问卷题 / 后台指标]
    - 验证结论：[核心变量划分出的用户，在辅助变量上是否呈现明显且可解释的差异]
    - 待验证项：[尚未被数据证明、仍属假设的部分]
  > 若无定量数据：本次为**定性人物角色，未做量化验证，划分依据偏主观**，建议后续按上「验证设计」补做。
```

## 五、形态示意（仅示范"长什么样"，**勿照抄内容**——务必按真实材料重写）

> 下例是凭空编的格式演示，不是任何正典内容，也不针对真实项目。看完格式即弃。

```
本次基于 6 位用户访谈，采用「定性人物角色」创建方法（无定量数据，未做量化验证），
按核心变量 **「网购决策依据（价格 ⇄ 品质）」** 划分出 3 类典型用户。

## 角色 1：精打细算的凑券达人

- 照片：[占位——一位边比价边记笔记的年轻女性形象]
- 基础信息：26–32 岁 · 女 · 二三线城市 · 月收入 6–9k（区间代表值）· 已育一孩
- 特征标签：价格敏感↑ · 囤货倾向↑ · 促销规则钻研者 · 比价跨平台
- 典型语录："同样的东西，我一定要凑到满减最划算才下单。"
- 用户故事：家里日用品按箱囤，关注好几个"薅羊毛"群，购物车常年躺着等降价的东西……
- 使用行为：大促前集中下单；常用功能=购物车/优惠券/比价；先加购、等价格触发再清空购物车
- 需求及痛点：
    - 表层痛点："满减规则太复杂，算半天怕算错。"
    - 深层需求：要的不是"更多优惠券"，而是"确信自己买到了全网最优价"的掌控感与安全感
- 核心建议：把"已是最优价/帮你算好最划算组合"显性化，降低凑单心算负担，强化"省到了"的确定性
- 支撑证据：用户A、用户C、用户F；"我一定要凑到满减最划算" —— 用户A

  > 标注：所用同理心地图/洞察框架依据当前为 draft 的正典；样本 6 人，划分待问卷验证。

## 用户划分依据
- 创建方法：定性（仅访谈、无定量数据）
- 核心变量：网购决策依据（价格⇄品质）；辅助变量：年龄、城市线级、品类偏好
- 量化验证：无定量数据，本次未验证；建议设 1 道单选题（"下单最看重价格还是品质"）+ 后台客单价/优惠券使用率交叉验证
```
> 注意上例如何把语录/行为挂回具体用户、如何把"需求"从表层痛点拔到深层、如何就地标 draft 与"未验证"——**形式照此，内容必须按真实材料和研究目标重新生成**。
