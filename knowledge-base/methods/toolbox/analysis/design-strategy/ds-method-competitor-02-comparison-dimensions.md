# 竞品分析 / 02 对比维度


## 目标

建立稳定的对比口径，让竞品分析从“截图罗列”转向“模式判断”。

## 常用维度

| 维度 | 关注问题 | 输出 |
| --- | --- | --- |
| 模式 | 竞品如何组织玩法、入口和能力 | 模式差异 |
| 阶段 | 如何表达前置、进行、等待、结束 | 阶段表达方式 |
| 信息位置 | 关键信息出现在什么页面、流程节点或反馈位置 | 信息组织方式 |
| 规则 | 复杂规则如何前置、合并、下沉或解释 | 规则策略 |
| 反馈 | 行动后如何确认、提醒、回访 | 反馈闭环 |
| 维护 | 是否降低运营配置和异常场景成本 | 维护启发 |
