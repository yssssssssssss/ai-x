# 用户分析 / 00 模块总览


## 定位

用户分析子模块用于回答“用户是谁、在什么任务里为什么卡住、这些卡点如何影响体验和业务结果”。

## 适用输入

- 用户访谈、问卷、客服反馈、用户之声
- 行为路径、点击数据、转化数据、流失数据
- 页面截图、流程录屏、可用性测试记录
- 业务目标、目标人群、项目边界

## 核心产出

- 用户类型与关键差异
- 任务路径与触点拆解
- 用户卡点、情绪变化与根因判断
- 可被设计策略承接的用户洞察

## 文件结构

| 编号 | 文件 | 用途 |
| --- | --- | --- |
| 00 | 模块总览 | 定义用户分析范围和产出 |
| 01 | 分析边界 | 明确用户、场景、任务、目标 |
| 02 | 用户分层 | 建立用户类型和差异判断 |
| 03 | 旅程任务 | 拆解任务路径、触点和信息需求 |
| 04 | 痛点诊断 | 定位卡点、归因和影响 |
| 05 | 洞察输出 | 收敛可用于策略推导的结论 |
