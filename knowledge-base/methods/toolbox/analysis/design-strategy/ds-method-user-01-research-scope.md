# 用户分析 / 01 分析边界


## 目标

在开始分析前，明确本次用户分析服务于哪个项目、哪类用户、哪个任务阶段和哪种设计决策。

## 需要确认

| 项目 | 说明 | 结论 |
| --- | --- | --- |
| 分析对象 | 页面、模块、链路、活动阶段或业务能力 |  |
| 核心用户 | 新用户、老用户、高意向用户、价格敏感用户等 |  |
| 使用场景 | 时间、渠道、状态、任务背景 |  |
| 用户目标 | 用户想完成什么、避免什么、确认什么 |  |
| 业务目标 | 转化、留存、履约、降本、复用等 |  |
| 设计决策 | 本次分析要支持什么方案判断 |  |

## 判断原则

- 不把所有用户混成一个平均用户。
- 不把业务目标直接写成用户痛点。
- 不在场景不清时直接进入方案判断。

## 输出物

- 用户分析边界表
- 待补充材料清单
- 初步假设与待验证问题
