# 竞品分析 / 00 模块总览


## 定位

竞品分析子模块用于回答“行业中相似问题如何被组织、表达、承接和取舍”，为设计策略提供外部参照。

## 适用输入

- 竞品页面截图、流程录屏、规则说明
- 行业案例、活动机制、产品能力说明
- 本品现状截图、业务规则、触点结构
- 用户痛点和项目目标

## 核心产出

- 竞品选择逻辑
- 对比维度和分析框架
- 可借鉴的模式、触点、规则和能力
- 不适合照搬的风险判断

## 文件结构

| 编号 | 文件 | 用途 |
| --- | --- | --- |
| 00 | 模块总览 | 定义竞品分析范围和产出 |
| 01 | 竞品选择 | 明确对标对象和选择理由 |
| 02 | 对比维度 | 建立分析口径 |
| 03 | 模式分析 | 归纳竞品处理复杂问题的方式 |
| 04 | 机会风险 | 判断可借鉴点和限制 |
| 05 | 洞察输出 | 收敛竞品启发 |
