# 竞品分析 / 05 洞察输出


## 目标

把竞品分析收敛成可用于策略推导的外部启发。

## 洞察模板

| 竞品洞察 | 证据 | 对应本品问题 | 策略启发 | 风险 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

## 输出原则

- 用“模式启发”替代“照抄页面”。
- 同时说明借鉴价值和限制条件。
- 每条洞察尽量对应到本品的触点、规则、链路或能力。

## 可交付内容

- 竞品洞察摘要
- 机会点与风险点
- 可进入设计策略的外部参照
