# 设计策略 / 01 问题定义


## 目标

把分散证据收敛为 2 到 4 个高阶问题，说明为什么必须做设计策略，而不是只做单点优化。

## 问题定义模板

| 高阶问题 | 证据来源 | 根因 | 用户影响 | 业务影响 | 设计机会 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

## 常见问题类型

| 类型 | 表现 | 策略方向 |
| --- | --- | --- |
| 认知混乱 | 名称、阶段、时间、状态不一致 | 统一心智和语义 |
| 感知复杂 | 信息过多、重复、分散、主次不清 | 收敛信息和触点 |
| 路径受阻 | 入口不清、反馈不足、无法回溯 | 打通链路和反馈 |
| 规则难懂 | 门槛、资格、例外和互斥不清 | 分层解释和规则治理 |
| 能力断点 | 用户想做但产品不能承接 | 补齐能力和回访机制 |

## 输出物

- 高阶问题陈述
- 证据链
- 策略机会定义
