# 设计策略 / 00 模块总览


## 定位

设计策略子模块用于把用户、竞品、业务和数据证据转译成可评审、可落地、可验证的设计方向。

## 适用输入

- 用户痛点和用户洞察
- 竞品模式和机会风险
- 业务规则、约束、目标和资源
- 数据表现、优先级和验证指标

## 核心产出

- 问题定义和归因
- 策略地图
- 优先级、路线图和验证计划

## 文件结构

| 文件 | 用途 |
| --- | --- |
| 模块总览 | 定义设计策略范围和产出 |
| 问题定义 | 从证据收敛高阶问题 |
| 策略地图 | 从痛点推导策略层和措施 |
| 优先路线 | 判断优先级和落地节奏 |
| 评审验证 | 支持汇报、决策和上线后验证 |
