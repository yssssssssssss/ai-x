# 用户分析 / 03 旅程任务


## 目标

按照用户完成任务的真实顺序，拆解触点、动作、信息需求、情绪变化和阻断点。

## 旅程拆解

| 阶段 | 用户目标 | 用户动作 | 关键触点 | 信息需求 | 情绪状态 | 风险 |
| --- | --- | --- | --- | --- | --- | --- |
| 发现 |  |  |  |  |  |  |
| 理解 |  |  |  |  |  |  |
| 决策 |  |  |  |  |  |  |
| 行动 |  |  |  |  |  |  |
| 等待 |  |  |  |  |  |  |
| 回访 |  |  |  |  |  |  |

## 关注点

- 用户是否知道当前是什么。
- 用户是否知道下一步会发生什么。
- 用户是否能找到关键决策信息。
- 用户是否能顺畅完成动作并获得反馈。

## 输出物

- 用户旅程表
- 关键触点列表
- 信息需求和反馈需求清单
