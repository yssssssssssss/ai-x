# 用户分析 / 04 痛点诊断


## 目标

把零散问题归因为可被设计解决的体验痛点，避免只罗列现象。

## 诊断层级

| 层级 | 判断问题 | 典型表现 |
| --- | --- | --- |
| 心智层 | 用户是否理解当前状态和阶段 | 名称不一致、阶段歧义、时间表达混乱 |
| 信息层 | 用户是否抓得住关键决策信息 | 信息分散、优先级冲突、规则后置 |
| 链路层 | 用户是否能连续完成任务 | 入口不清、路径阻断、反馈不足 |
| 能力层 | 产品能力是否承接真实任务 | 不能提醒、不能收藏、不能回溯 |
| 规则层 | 规则是否可理解、可预期 | 门槛不清、资格限制不前置、例外场景复杂 |
