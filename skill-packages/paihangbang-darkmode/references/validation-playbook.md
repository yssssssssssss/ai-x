固定验收项
原画板未修改。
副本位置、尺寸、内部结构与原画板一致。
副本根节点已进入暗色模式，或透明报告无法切换的原因。
冻结区域未被修改。
产品化 UI 的背景、文字、边框、图标、蒙层具备合理暗色层级。
正文对比度参考 WCAG AA 4.5:1，大字和关键非文字图形参考 3:1。
没有明显跨角色误绑，例如白底绑红色、文字绑背景、边框绑正文色。
渐变 stop、透明叠加、局部文本、SVG 和实例区域已检查。

视觉风险检查

重点检查：

产品化 UI 中仍存在视觉可见的高亮白底。
页面根 / feed 外底是否落到 #14171a 层级。
Tab 行 / 页面承托 / 卡片 / 楼层是否落到 #1f2226 层级。
chip / 块状 Tab / 小方块是否落到 #2a2f36 层级。
Tab 行、块状 Tab、筛选 chip、小方块背景是否移除了不必要的外描边，尤其是 0.5px、约 7.84% 透明度描边。
文字在深色背景上对比度不足。
低透明白/黑在暗色模式下过亮或过暗。
商品图被误改色。
运营头图被误拆解或误绑 token。
白色背景误绑 primary/brand。
被上层暗色 paint 覆盖的旧白色 fill 不直接判失败；只有视觉可见白底才判失败。
失败时报告

如果无法完成 token 绑定，不要说“完成”。应报告：

已创建副本。
是否成功切暗色模式。
冻结区清单。
未绑定数量。
未匹配 token 数量。
fallback 数量。
需要设计师确认的问题。
非排行榜通用页面验收

generic-home-like 页面验收重点：

除标准商品流商卡外，首焦、腰部楼层、运营模块、天天领惊喜、Joy Agent、底部 Tab 等冻结区未被改色。
标准商品流商卡的卡片底、标题、价格、促销、加购按钮具备暗色层级。
头部 Tab 文案可见：未选中 #e1e6eb / #ffffffcc，选中保留 #ff0f23，结构不删除不隐藏。
不新增卡片/楼层描边；错误描边为 0。
自营标、商品图、LOGO、图片内贴纸/文字保持原稿。
