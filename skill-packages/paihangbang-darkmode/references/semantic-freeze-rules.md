语义分区与冻结规则
目标

暗黑适配前先判断区域语义。运营/切图区域不参与变量绑定，不拆解、不换色；只处理产品化 UI。

区域类型
页面类型

先判断页面类型，再套冻结策略：

类型	说明	默认策略
ranking-channel	排行榜频道、金榜、商品榜、店铺榜、美食榜、AI 全网评等榜单聚合页	使用排行榜频道规则，商卡/店铺卡正常适配，Banner/商品图冻结
generic-home-like	新品页、首页-like、普通频道页、非排行榜通用页面	除标准商品流商卡外，运营楼层默认冻结；头部产品化 Tab 可适配
mixed	同时包含榜单商卡与普通运营楼层	标准商卡适配，运营楼层冻结；不确定处标“待设计师确认”

generic-home-like 识别线索：节点/画板名含 新品、首页、好货、特价、秒送，或结构中出现首焦、腰部楼层、运营卡片、Joy Agent、底部 Tab、普通商品流瀑布流，而不是排行榜/金榜聚合页。

类型	说明	默认处理
product-ui	产品化 UI，如页面背景、卡片、文字、按钮、Tab、筛选、分割线	可切模式、可补绑
operational-image	运营视觉、频道头图、banner、商品图、切图交付区	整体冻结
mixed	产品 UI 与运营视觉混合	只处理明确 UI 子层，其余冻结
head-ui-inverse	运营头图上的状态栏、返回、更多、标题等 UI	保持浅色/白色反显，不按白底风险处理
unknown	无法判断是否产品化	跳过，待设计师确认
必须冻结
运营感重的 banner、KV、主视觉、会场头图、频道头图、排行榜头图、金榜头图。
商品图、模特图、品牌图、运营素材图。
通过多个色块、渐变、矢量、装饰形状绘制，但实际开发会整体切图交付的区域。
排行榜频道聚合页里的 Banner/楼层图片内容、插画、素材、商品图和图片内文字/图标整组冻结；不要额外加黑色遮罩，只允许适配 Banner 所在外层页面/楼层承托背景。
频道页 Banner 结构即使不叫 容器 20121215029 也必须整组冻结；路径/节点名含 banner、容器 20121213730、容器 20121213732、楼层双列、排行榜招商、春节年货、全站热卖、全站折扣、全站热卖排行、全站折扣排行 时，Banner 根容器、卡片底、标题、副标题、箭头、商品图、素材图、图片内文字和装饰都冻结；不要改 Banner 根容器为暗色。只允许适配 Banner 所在页面/楼层背后的承托背景。
商品图左上角等非标准形状标签、贴纸、异形角标、特殊装饰标签。
顶部导航 / 顶导航 / NavBar / 状态栏，默认冻结当前视觉；若位于头图上则归为 head-ui-inverse。
商卡上的色块标签默认冻结；自营标全局冻结，不管在什么页面、是否属于标准产品化标签，都不做 V16 重绑定、不切暗、不 fallback 改色。
商品图内部/左上角的上榜理由贴纸或非标角标冻结；图片上的标签整组冻结，包含文字；商卡信息区内的上榜理由标签不冻结。
频道/排行榜商卡中路径或节点名含 属性1=透底图、矩形 5862、排名标、排名标小 且位于商品卡图片区域时，按商品图整组冻结，包含商品图、图内排行标、排行标文字和图片承托形状；不要因为其父级是 属性1=商品榜 / 榜单卡片区域 就当作产品化卡片底改色。
店铺榜卡片根节点含 属性2=商品图109 时，不代表整张卡都是商品图，不能冻结整卡；只冻结其内部真实图片/品牌资产子层，如 商品图109/商品图、商品图109/矩形 5862、商品图109/排名标、商品图109/排名标小、店铺LOGO。店铺榜卡片底、榜单标题、店铺名称、粉丝数/老店文案、查看榜单入口都属于产品化 UI，应正常暗黑适配。
非排行榜通用页面（generic-home-like）中，除标准商品流商卡外，运营楼层默认冻结，不管是否进入 feeds/content 区；例如首焦、腰部楼层、天天领惊喜、试用/限量/抽签/红包/营销模块、Joy Agent、底部导航/毛玻璃组件、强运营卡片都冻结。
通用页面的头部区域如果是花哨图片/运营视觉，整体冻结；如果是产品化浅色/简单背景，可暗化背景并保留文字反白：未选中文案用 #e1e6eb 或 #ffffffcc，选中态保留品牌红 #ff0f23，外卖 等头部功能小标签跟随原视觉或高对比可读色。
不确定是否切图的装饰区。
应参与适配
页面背景、内容背景、卡片背景。
商品卡片底色、商品标题、价格、利益点文案、产品化按钮、加购按钮。
标准 Tab、筛选项、分割线、描边、蒙层、普通按钮。
频道一级导航选中承托底参与适配：如 属性1=选中左侧页签 下的 路径 44，以及 常规页签 下的 联集 34、路径 44、路径 45，目标色为 #1f2226；不要因为父级属于频道头部导航就整体冻结该承托底。
排行榜/金榜等产品化标签；商卡信息区内的上榜理由标签参与适配；但如果标签位于商品图内部或属于商卡色块标签则默认冻结；自营标无条件冻结。
识别线索

判为 operational-image 的强线索：

节点名含 banner、头图、频道头图、运营、会场、主视觉、KV、背景图、排行榜头图、金榜、热卖头图。
位于页面顶部或模块头部，面积较大，视觉像海报而非控件。
子节点包含大量图片 paint、复杂 SVG、渐变、装饰图形、特殊字体或高色彩数量。
出现商品图、模特图、奖杯、金属光效、丝带、贴纸、异形标签。
文案具有强运营属性，如“官方购物指南”“金榜”“爆款”“热卖”“趋势”“大促”。

判为 product-ui 的强线索：

结构化重复列表、商品卡片、标准按钮、标准标签、Tab、筛选、价格、标题、利益点。
颜色角色清晰，属于 background、surface、text、border、primary、mask 等 UI token 类别。
与商品图/运营图分离，开发时通常由原生 UI 或前端组件实现。
保守原则

不确定时不要改。输出为“待设计师确认”，不要为了完成效果而绑定或写死颜色。
