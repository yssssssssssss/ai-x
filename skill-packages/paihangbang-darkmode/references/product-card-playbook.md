商品卡暗黑适配 Playbook
目标

商品榜/商品卡类页面不只要“没有白底”，还要建立暗黑模式下的组件层级：页面底、卡片底、商品标题、辅助信息、标签、价格、加购按钮都应有明确角色。

背景层级

页面背景和商卡背景必须是两种不同深灰，不能同色，也不能保留日间白底。

角色	推荐暗色	说明
页面最底 / 画布背景 / feed 外底	#14171a	频道、强暗黑频道、金榜/真榜/O2O 榜单统一页面底
频道 icon 区 / Tab 行背景 / 页面承托	#1f2226	作为承托面，不保留日间白底
一级 Tab 承托 / 频道选中凸起底	#1f2226	承接页面与卡片之间的楼层面
商卡底 / 卡片底 / 楼层底	#1f2226	与页面底 #14171a 形成层级
未选中小方块 / 块状 Tab / 二级筛选弱容器	#2a2f36	未选中文字使用 #a1a9b3
红色弱底	#40262a	用于选中态、弱红色标签/按钮底

验收：

页面背景不得是 #ffffff / #f2f3f5 / #f5f6fa 等日间浅色。
商卡背景不得是日间白底。
页面底和商卡底必须有可见层级差。
商品卡文字层级
元素	推荐暗色/角色
商品标题 / 主标题	#e1e6eb / title
参数 / 卖点 / 正文	#a1a9b3 / text
弱辅助 / 划线价	#717985 / help
价格 / 促销红	#ff0f23 / primary
服务金 / 金榜文案	#b38b6d 或 #f2dbc2，仅在确认为金榜/服务语义时使用

验收：

商品标题不能保留日间深色：#11141a / #171a26 / #1a1a1a / #00000033。
辅助文字不能比标题更亮。
价格红保持品牌识别。
商品图与非标标签

冻结：

商品图。
商品图内部/左上角非标准形状角标、贴纸、异形标签。
图片上的标签整体冻结，包含标签底、标签描边和标签文字，不要只冻结底色却改文字。
菜品图、商品图、店铺图上的 TOP/榜首/贴纸/角标及文字整组冻结。
排行榜/频道商卡中的 属性1=透底图、矩形 5862、排名标、排名标小 默认视为图片区域，整组冻结，包含图内排行标底、文字和商品图承托；不要按普通卡片背景或服务标签改色。

不冻结：

商卡信息区内的标准产品化标签。
上榜理由标签。
加购按钮。
上榜理由标签

上榜理由标签属于产品化 UI，默认参与暗黑适配，不再归入冻结区。

建议：

标签底：primaryLight #40262a、serviceBg #3a2b1a 或弱 surface，按语义判断。
标签文字：primary #ff0f23、serviceText #b38b6d 或 title #e1e6eb。
如果标签位于商品图内部且是非标准贴纸，仍按商品图切图区冻结。
加购按钮

加购按钮属于产品化操作按钮，默认参与暗黑适配。

建议：

+ 号：primary #ff0f23。
按钮底：primaryLight #40262a 或低透明弱红底。
圆形按钮容器不能保持日间浅粉白底。
保证按钮与卡片底有可见对比。
成组语义一致性

同一语义组内的图标和文字必须统一颜色角色，不要拆成两种颜色：

4.8分：数字和“分”应使用同一角色色。
起送 ¥38 / 免运费：同一配送信息组应统一为 text/help 或 primary，不要红灰混乱。
庙行镇 icon / 庙行镇：地址 icon 和地址文字应使用同一 text/help 角色色。
同一优惠组内 优惠类型 / 优惠信息 需保持同一促销语义。
淡粉/弱红底

下单返、满减、加购弱底、浅粉促销底都属于弱红色产品化 UI，不能保留日间淡粉。

建议：

弱红底：primaryLight #40262a。
日间淡粉如 #fff1f1、#fff0f4、#ffebf1、加购/满减/下单返底色，暗色统一转 #40262a。
红色文字/图标：primary #ff0f23。
如果该标签位于商品图内部且是非标贴纸，仍冻结。
处理优先级

P0 必修：

页面底 / 列表底。
商品卡片底。
商品标题暗底暗字。
商品/美食卡片正文暗底暗字。
加购按钮日间浅底。

暗底暗字默认直接修复，不需要向用户确认。

P1 修补：

上榜理由标签。
参数/卖点/划线价层级。
卡片描边/分割线透明度。

P2 保留：

商品图。
商品图内非标贴纸/角标。
自营标全局冻结：不管在什么页面、是否属于标准产品化标签，都不受暗黑模式影响，包含底色、文字、描边、组合色块及内部子层。
风险指标
pageCardContrastRisk：页面底与商卡底无层级。
darkTextOnCardRisk：商品标题或核心文案在暗底上过暗。
reasonTagNotAdaptedRisk：上榜理由标签仍为日间浅色或不可读。
addCartNotAdaptedRisk：加购按钮仍为日间浅粉/白底或 + 不可见。
promoLightBgRisk：下单返、满减、加购等弱红底仍保留日间淡粉。
groupColorInconsistentRisk：同组图标/文字颜色不一致，如评分、配送、地址。
secondTabWhiteBgRisk：二级 tab 或筛选行仍为白底。
multiLayerBgRisk：产品化背景多层浅色叠加，导致局部灰块/白块异常。
aiOverPurpleRisk：仅因节点名或标题含 AI 被过度匹配为 AI 紫色。
非排行榜通用页面商卡

在 generic-home-like 页面中，只让标准商品流商卡参与暗黑适配。标准商卡通常具备以下结构：商品图 + 标题/商品名 + 价格/促销 + 自营标/标签 + 加购/按钮；一排一商卡和双列瀑布流商卡都算，Frame 19406857* 这类商品流卡片结构也算。

不算标准商卡、默认冻结的模块：

首焦 / A1A2 / 腰部楼层 / 运营楼层。
天天领惊喜、试用领取、限量尖货、抽签、红包、营销活动卡。
Joy Agent、底部 Tab、毛玻璃组件、强运营推荐楼层。
商品图、背景图、品牌图、LOGO、图片内文字和贴纸。

通用页面中默认不要给商卡、楼层、Frame 19406857* 或 inner card 自动新增描边。只在原本就有必要分割线/输入框/按钮边界时保留或调整；错误出现的 #ffffff1f、0.5px 低透明描边应清理。
