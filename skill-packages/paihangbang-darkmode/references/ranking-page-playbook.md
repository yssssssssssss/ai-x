排行榜/金榜页面暗黑适配 Playbook
目标样本

用户确认的正确样本：

排行榜11_暗黑适配2：7:24108
金榜频道_暗黑适配2：7:22353

这些样本说明：排行榜/金榜类页面的理想暗黑稿通常不是通过全量 fallback 改色得到，而是通过正确绑定 V16 后切换暗色模式得到。

核心原则
先 V16 体系化，再切暗黑；只修明确错误，不大规模改文字/标签/小组件。

默认策略
复制副本。
语义分区，冻结高风险区域。
对非冻结产品化 UI 做 V16 light token 重绑。
切暗色模式。
只修大面积浅底、透明度错误和明确不可读问题。
默认冻结/保留
区域	处理
背景图-榜单、真榜头图、频道头图、主视觉	冻结
顶部导航、状态栏、返回、更多、搜索	head-ui-inverse，保留浅色反显
横向大频道/父子嵌套导航	默认保留，不强制 fallback
tab/chip/button 小面积选中态	默认保留或轻量修补，不强制深色化
商卡色块标签、自营标	冻结；自营标全局不受暗黑模式影响
商卡信息区内的标准上榜理由/服务标签	产品化 UI，按 red/service 语义适配；若在商品图内部则冻结
商品图	冻结
商品/榜单卡片大面积白底	必修
feeds / 内容区大面积白底	必修
不要做的事
不要因为 #ffffff 出现多，就判定失败。
不要把所有 tab / 按钮 / 类目文字改成金色。
不要把普通商品标题、类目文字、tab 文案默认映射为 serviceDecor。
不要把运营头图里的金色、红色、白色逐层绑定。
不要逐层改排行榜频道 Banner/楼层里的图片内容、插画、素材、商品图或图片内文字；不要额外加黑色遮罩，只处理外层页面/楼层承托背景。
不要把小面积 icon、反白文字算作大面积白底风险。
排行榜频道聚合页

用户确认的频道聚合页参考样本：频道页效果，节点 366:36185。

页面类型区分：

落地页：有大头图，头图内通常有居中标题，是用户到达排行榜末级页面后的页面。当前落地页暗黑适配规则已被用户认可，不要被频道聚合页规则反向覆盖。
排行榜频道聚合页：用户到达落地页前的一步，是聚合多个排行榜/商品/频道入口的频道页。需要单独识别。

聚合页规则：

banner 位小方块 / Banner 楼层：整组图片内容冻结不适配；不要逐层改图片内容、插画、素材、商品图、图片中的文字或图标，也不要额外加黑色遮罩。只允许适配 Banner 所在外层页面/楼层承托背景，例如 #1f2226。
商卡不论一排一还是一排三，都沿用商卡适配方式：商品图冻结；卡片背景、标题、卖点、价格、利益点、按钮等产品化 UI 正常暗黑适配。
商卡图片区域冻结边界要包含 属性1=透底图、矩形 5862、排名标、排名标小 及其文字；这些是商品图/图内排行标，不应被改成卡片底或服务色。
店铺榜卡片根节点若含 属性2=商品图109，仍按店铺卡 product-ui 处理，不能整卡冻结；只冻结其内部 商品图109 图片子层、矩形 5862、图内排行标和 店铺LOGO。店铺卡底、店铺名称、粉丝数/老店文案、查看榜单入口正常暗黑适配。
频道一级导航选中承托底要适配，例如 属性1=选中左侧页签 下 路径 44，以及 常规页签 下 联集 34、路径 44、路径 45 应改为 #1f2226；但内部频道 icon/运营视觉仍按冻结/保留处理。
红色与金色必须一一对应，不能互相混用：红色促销/操作/品牌强调保持 primary；金色/服务/金榜语义走 serviceBg/serviceText。
普通频道类目文案、普通 Tab 文案不因含“榜”或“好评”自动转金色。
查看榜单 这类普通入口的箭头跟随入口文字色，默认用 title/text 层级，不因所在卡片含“榜”而转 service/gold；只有金榜品牌标识、麦穗、服务金标签等明确金色语义才用 service/gold。
商品图、头图、运营视觉、一级频道视觉资产仍冻结。
金色/服务色使用范围

仅以下场景优先使用 service/gold 语义：

金榜品牌标题。
麦穗、榜单装饰。
服务金相关产品化标签。
明确含 金榜 / 服务 / service 且不是普通 tab/类目文案的节点。
服务/棕金标签内的“好评 / 买后说好 / 免费上门测量”等服务语义。

普通类目文案如 推荐、手机通讯、大家电、家居家装 不应默认变金色；二级 Tab 文案如 好评榜 也不应因含“好评”变金色，应保留当前视觉或使用 text/title/help 角色。

fallback 边界

fallback 只处理 P0/P1 问题：

级别	说明	处理
P0	页面根、feeds、商品/榜单卡片仍是大面积白底	fallback 或绑定 V16
P1	边框/蒙层不透明、内容区层级糊	fallback 修补
P2	白色文字、图标、小按钮、tab 选中态、导航反白	默认保留
验收

必须通过：

大面积白底风险为 0 或仅剩明确冻结/保留项。
商品图未被反色。
头图主视觉未被破坏。
顶导航/状态栏仍清晰。
商品/榜单卡片底色合理暗化。
红色价格/品牌强调保留。
金色/服务色不过度泛化。
