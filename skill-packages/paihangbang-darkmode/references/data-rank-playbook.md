该样本代表“数据榜类页面一次生成的目标效果”。后续数据榜类暗黑适配应优先对齐此样本的视觉层级，而不是追求 100% token 绑定。

第一性定位

该 skill 的目标是生成可用的暗黑设计稿，不是单纯做 token 自动绑定。

交付优先级：

视觉层级正确。
运营/切图资产不被破坏。
产品化 UI 符合 V16 暗黑语义。
能绑定 V16 token 就绑定。
无法绑定但角色明确时允许 fallback，并在报告中标注。

数据榜商品卡规则
商品卡片底：surface，推荐 #1f2226；不再默认使用 #11141a 作为卡片底。
商品图 / 菜品图 / 图片占位底：冻结，不反色，不绑定；日间 #ffdddd 这类图片占位底不要误判为促销弱底。
商品标题：title，推荐 #e1e6eb。
自营/秒送/品牌色块标签：默认冻结，保持 #ff3333、#ffd939、#665005、白字等原设计色；除非用户明确要求适配。
价格、促销、同款低价：primary，推荐 #ff0f23。
划线价、参数、辅助利益点：text/help，推荐 #a1a9b3 / #717985。
上榜理由底：棕金/服务语义时必须用 serviceBg #3a2b1a，对应日间 #fff4e0；红色促销语义才用 primaryLight #40262a；如果在商品图内部则冻结。
加购按钮：保留品牌红语义或红色弱底，不应变灰。
风险判断规则

不要把浅色文字当成白底风险。

仅当同时满足以下条件时，才判为“大面积日间白底风险”：

节点不是 TEXT。
不是图标小件。
width × height > 1000。
fill 亮度高且 opacity > 0.55。
不属于冻结区或 head-ui-inverse。

TEXT 使用 #e1e6eb 是合理暗黑强文本，不应被计入风险。

上下对比案例补充

参考页 page_id=10:1 的“上下对比”案例包含复购-店、复购-菜、热销-店、热销-菜、好评、AI全网评、只有一级 Tab 页面。抽取结论：

页面根常见 #f2f3f5，暗黑后必须压到页面底 #14171a，不再默认压到纯黑。
二级 Tab 行常见整行 #ffffff，暗黑后不能残留可见白底，应转 #1f2226。
二级筛选 chip 未选中常见 #f0f2f7 / #ffffff，暗黑后转 #2a2f36，文字 #4f5259 转 #a1a9b3。
二级筛选选中常见 #ffe8ee + #ff0f23，暗黑后底转 #40262a，红色文字/描边保持 #ff0f23。
一级频道选中承托底常见 联集 34 #ffffff，必须下钻到 BooleanOperation/Vector 等真实承载 paint 修复为 #1f2226。
商品/店铺卡常见 #ffffff，暗黑后转 #1f2226。
服务金标签常见 #fff4e0 底、#80512d/#966530/#b5691a 字，暗黑后底转 #3a2b1a，字转 #b38b6d。
“部分标签”正确案例确认：上榜理由棕金标签正常态 #fff4e0 底 + #80512d 图标/文字/分割线；暗黑态 #3a2b1a 底 + #b38b6d 图标/文字，分割线可用 #b38b6d 或低对比 #4d443d；“免费上门测量”等棕金服务标签文字 #80512d → #b38b6d。
AI 全网评中只有星星、AI 品牌标识、紫色描边使用 AI 紫；普通评语正文、店铺名、卡片背景仍按普通文本/背景规则处理。
自营/秒送色块标签常见 #ff3333/#ffd939/#665005/#ffffff，默认冻结，不做 V16 重绑。
