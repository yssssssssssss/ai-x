# 阶段 6 · 设计语言推导

> 覆盖 G(设计落地)维度。把前面的"该做什么"翻译成"长什么样、怎么交互"。**核心信条:行业设计语言 = 平台规范(继承)+ 行业增量(补充),增量不得脱离平台。** 不是从零造一套视觉,而是站在京东平台【设计哲学】+【设计系统】之上,做行业特色的额外补充。每个色值、每个组件,都要能回答两件事:"平台有没有?"和"凭什么行业要在此之上加它?"

## 目标

用 0.5-1 天,在**平台基线之上**走完一条**可追溯的增量推导链**:
```
平台设计系统(基线·继承) → 品类属性 → 特色心智 → 行业视觉风格 → 交互形式补充
                              ↓ 约束
                所有增量落在平台"允许自定义区间"内,不覆盖平台 token
```
产出一套**不脱离平台、只做行业增量**的设计语言:能用平台的直接继承,行业特色只加在表现层,冲突时平台优先。

## 前置输入

- **`参考资料/京东设计哲学(平台基线).md`——不可动摇的基线**(智性设计哲学 + 4 价值观 + 6 原则 + 设计系统的色板 token、组件库、交互规范、字体系统)
- 阶段 5 的差异化定位(**视觉要服务于定位**,如"决策辅助专家"就该"清晰、可信"而非"花哨")
- 阶段 3 的视觉一致性问题(内诊发现的视觉短板,正是要解决的)
- 阶段 2 的竞品截图(看竞品视觉,找差异化空间)
- 模板:`模板/对比表-四要素.md`(视觉方向对比部分)

## 具体动作

### Step 0 · 对齐平台基线(必做,30 分钟)

**动手做行业增量前,先把平台底座摸清**。行业设计语言是长在平台上的,不是另起炉灶。基线分两层——先对齐**哲学层**(定方向),再对齐**系统层**(定素材)。

**① 哲学层(方向约束)**——读 `参考资料/京东设计哲学(平台基线).md`,回答:

```
□ 智性设计(理性创造×人文共情×科技赋能)对本品类视觉意味着什么?
   —— 如"理性创造"→ 克制、精准;"人文共情"→ 温度、关怀细节
□ 本品类主推方向,主要扛哪条价值观?(自然/务实/包容/焕新)
□ 视觉/交互要重点满足哪几条设计原则?(精巧克制/韵律之美/流畅一致/亲和友好/灵活拓展/牵引激发)
```

> 阶段 3 诊断出的视觉一致性问题违反了哪条原则,这里的视觉方案就要正面回应哪条。诊断与设计闭环。

**② 系统层(素材约束)**——列"平台基线清单":

```
京东平台【设计系统】提供了什么(要继承的):
□ 色板 token:平台的主色/中性色/功能色体系 —— 哪些固定?哪些留了自定义槽位?
□ 组件库:按钮/卡片/导航/输入框等平台标准组件 —— 哪些直接用?
□ 交互规范:手势、转场、反馈、无障碍等平台通行模式
□ 字体系统:平台字体族、字号阶梯、字重规范

明确两个区间:
- 【固定继承区】平台强制统一的,行业不能改(如核心功能色、基础组件行为)
- 【允许自定义区】平台留给行业风格化的空间(如主题色、内容化模块、行业专属卡片)
```

**避坑**:跳过这一步直接推品类属性,极可能推出一套和平台冲突的视觉——后面全得返工。**行业增量只能加在【允许自定义区】,固定继承区一律沿用平台;方向上不能违背智性设计哲学。**

### Step 1 · 提炼品类属性(30 分钟)

用 4-5 个关键词定义这个品类**本质上是什么**。属性来自品类客观特征,不是主观感受:

```
{品类}的核心属性:
1. ______(如 图书=知识)
2. ______(如 图书=情绪/陪伴)
3. ______(如 图书=文化/品味)
4. ______(如 图书=购物/交易)
```

**提炼方法**:问"用户和这个品类发生关系时,本质在获取什么?" 图书=获取知识与情绪;母婴=获取安心与专业;数码=获取性能与新潮。

**避坑**:属性别写成"高端""好用"这类通用褒义词。属性是**品类特有的**,换个品类就不成立才对。

### Step 2 · 推导气质关键词(20 分钟)

每个属性 → 对应 1-2 个视觉气质词。这是推导链的关键一跳,**要写出对应关系**:

```markdown
| 品类属性 | → 视觉气质 |
|---|---|
| 知识 | 沉稳、有序 |
| 情绪/陪伴 | 温暖、柔和 |
| 文化/品味 | 雅致、留白 |
| 购物/交易 | 清晰、可信 |
```

再叠加阶段 5 的**定位约束**:如定位是"决策辅助专家",则"清晰、可信"应被放大,"花哨"要被抑制。

最终收敛出 **3-4 个主气质词**,作为所有视觉决策的准绳。

### Step 3 · 列风格方向并对比(45 分钟)

基于气质词,提出 3-4 个候选风格方向。用 `模板/对比表-四要素.md` 的视觉方向对比表:

```markdown
| 方向 | 核心特征 | 适配场景 | 优点 | 局限 |
|---|---|---|---|---|
| A · 沉稳书卷 | 米白底/衬线标题/低饱和 | 强调知识与信任 | 契合"可信"气质;差异化于花哨竞品 | 可能偏冷,年轻用户吸引力弱 |
| B · 温暖陪伴 | 暖橙/圆角/手写感 | 强调情绪与陪伴 | 亲和;适合内容化 | 弱化专业感 |
| C · 清爽现代 | 白底/无衬线/高对比 | 强调效率决策 | 清晰;易落地 | 差异化不足,像通用电商 |
| D · 文艺留白 | 大留白/细字重/莫兰迪 | 强调品味 | 高级感 | 信息密度低,不适合货架 |
```

**每个方向都要能对应回气质词**,不是凭空造风格。

### Step 4 · 定主推 + 备用(20 分钟)

**主推 1 个 + 备用 1 个,其余仅列不推**(这是硬规则,避免"4 选 1 都想要"):

```markdown
- **主推**:方向 A · 沉稳书卷 —— 最契合"可信/知识"气质,且与竞品的花哨形成差异化
- **备用**:方向 C · 清爽现代 —— 若业务方更重效率转化、担心 A 偏冷,可切换
- (仅列)方向 B、D:各有长板但与当前定位契合度较低
```

选择理由要**扣回定位和气质**,不是"我觉得 A 好看"。

### Step 5 · 落地主推方向的色板(45 分钟)

色板必须四层齐全,每个 hex 都标用途:

```markdown
#### 基础色
- 主背景:`#XXXXXX`(如米白 #FAF8F3,呼应"书卷")
- 次背景:`#XXXXXX`

#### 内容主色
- 主色 1:`#XXXXXX`(用于:导航/主按钮)
- 主色 2:`#XXXXXX`(用于:辅助模块)

#### 强调色
- 强调 1:`#XXXXXX`(用于:CTA/促销,注意与主色的对比度)
- 强调 2:`#XXXXXX`

#### 中性色
- 文本主色:`#XXXXXX`
- 文本次色:`#XXXXXX`
- 分割线:`#XXXXXX`
- 禁用态:`#XXXXXX`
```

**避坑**:色板要**呼应气质词**。定了"沉稳"却给一套高饱和撞色,就是推导链断了。另外注意 CTA 强调色与背景的对比度(可达性)。

**平台增量约束**:色板不是从白纸开始配。**平台的中性色、功能色(成功/警告/错误)一律继承,不改**;行业增量只在平台【允许自定义区】扩展 1-2 个"品类主题色"。若品类需要的主色与平台功能色冲突(如想用红做主色但红是平台的错误色),**服从平台**,另选或标注"需平台侧确认"。

### Step 6 · 组件、交互与创新形态(30 分钟)

在主推方向下,说清关键元素的品类化调整:

- **组件**:**先复用平台组件库,不重新发明**。卡片圆角/阴影、按钮风格、标签、图片比例——只在平台组件的可配置区间做风格化调整,说清"平台给了什么、行业为什么在此之上微调"。平台已有的组件绝不另造一套。
- **字体**:主标题/正文的字体族、字重、字号层级——**继承平台字体系统的字号阶梯**,行业只调用不改阶梯
- **交互视觉**:哪些通用模式要调?(如详情页布局、tab 切换、下拉刷新样式)——平台交互规范(手势/转场/无障碍)固定继承,行业只加"品类专属交互"(如内容化模块的独有操作)
- **创新形态**:2-3 个前瞻性设想(如图书的"AR 试翻""语音伴读";母婴的"月龄时间轴")——标注为探索性,不承诺落地

**平台增量约束**:本步所有产出都要能标出"这是平台已有(继承)"还是"这是行业新增(增量)"。与平台规范冲突的,一律标"需平台侧确认",不擅自覆盖。

**中档到此即可;重档再补动效、字体细则、触控规范。**

## AI 辅助 prompt 示例

### 帮我提炼品类属性和气质

```
我在为京东「{品类}」频道推导设计语言。这个品类的差异化定位是「{阶段5的定位}」。
前提:京东平台已有统一的设计哲学和设计系统,行业设计语言只在其上做增量,不另起炉灶。
请帮我:
1. 提炼这个品类的 4-5 个核心属性(要品类特有的,不是"高端/好用"这类通用词)
2. 每个属性推导出 1-2 个视觉气质关键词,写出对应关系
3. 叠加定位约束后,收敛出 3-4 个主气质词
4. 提示:这些气质最终要落到"平台允许自定义的区间"(如主题色、内容化模块),而非改动平台基础规范
```

### 帮我做风格方向对比

```
京东「{品类}」的视觉气质关键词是:{关键词}。定位是:{定位}。
竞品的视觉现状:{竞品甲偏花哨、竞品乙偏冷淡...}

请提出 3-4 个候选风格方向,用四要素对比表拆解(核心特征/适配场景/优点/局限)。
要求:每个方向都能对应回气质关键词;至少有一个方向能和竞品形成差异化。
最后推荐 1 个主推 + 1 个备用,理由要扣回定位和气质,不要用"好看"这类主观词。
```

### 帮我生成色板

```
主推视觉方向:{方向名 + 核心特征}。气质关键词:{词}。
请生成一套四层色板:基础色/内容主色/强调色/中性色,每个给 hex 值和用途说明。
要求:
- 色彩要呼应气质关键词(如"沉稳"就别高饱和撞色)
- CTA 强调色与背景要有足够对比度(注明对比度是否达 WCAG AA)
- 中性色要成体系(文本主/次/分割线/禁用态)
```

### 帮我想创新形态

```
京东「{品类}」的属性是 {属性},定位是 {定位}。
请设想 2-3 个前瞻性的视觉/交互创新形态,要求:
- 从品类属性自然生长出来(不是硬套 AR/AI 噱头)
- 每个说清:形态是什么、解决什么体验问题、为什么适合这个品类
- 标注为探索性设想,不承诺落地
```

## 三档差异

| 项 | 轻档 | 中档 | 重档 |
|---|---|---|---|
| 推导链 | 属性→气质→1 主推方向 | 完整对比表 | 完整 + 市场视觉扫描佐证 |
| 色板 | 主推方向色板(四层) | 四层 + 用途 | 四层 + 明暗双版 + 可达性校验 |
| 组件 | 跳过或极简 | 卡片/按钮/图片 | 全组件库规范 |
| 字体 | 跳过 | 层级规范 | 完整字体系统 |
| 交互/动效 | 跳过 | 关键模式调整 | + 动效/触控/微交互 |
| 创新形态 | 1 个 | 2-3 个 | 3+ 个含草图 |

## 自检清单

- [ ] 品类属性是**品类特有的**(换个品类不成立)
- [ ] 属性→气质有**明确对应关系**(不是各写各的)
- [ ] 气质词叠加了阶段 5 的定位约束
- [ ] 风格方向每个都能对应回气质词
- [ ] **只主推 1 个 + 备用 1 个**,不是 4 个都推
- [ ] 主推理由扣回定位/气质,不是"好看"
- [ ] 色板四层齐全(基础/内容/强调/中性),每个有 hex 和用途
- [ ] 色板呼应气质词(如"沉稳"不配高饱和撞色)
- [ ] CTA 强调色与背景对比度达标
- [ ] 有 2-3 个创新形态,从品类属性生长出来

- [ ] 所有增量都标出了"平台已有(继承)"还是"行业新增(增量)"
- [ ] 增量都落在平台【允许自定义区】内,固定继承区未被覆盖
- [ ] 与平台规范冲突的项都标了"需平台侧确认",没有擅自覆盖

## 常见坑

- **坑 1**:视觉方向从"我觉得好看"来,而非从品类属性推导 → **每一步都要能追溯上一步**,这是本阶段的立身之本。
- **坑 2**:品类属性写成"高端/好用/丰富"通用词 → **必须品类特有**,换品类就不成立才对。
- **坑 3**:4 个方向都想要,不做取舍 → **硬规则:主推 1+备用 1**,其余仅列。
- **坑 4**:定了气质"沉稳"却配高饱和撞色 → **色板与气质脱节=推导链断裂**。
- **坑 5**:色板只给主色,不给中性色和用途 → **四层齐全**,否则前端没法落地。
- **坑 6**:创新形态硬蹭 AR/AI 噱头 → **要从品类属性自然生长**,能说清为什么适合这个品类。
- **坑 7**:忽略阶段 3 发现的视觉一致性问题 → 设计语言的首要任务就是解决那些割裂,别另起炉灶。
- **坑 8**:另起炉灶造一套和平台冲突的视觉/交互 → **行业设计语言长在平台上,不是替代平台**。先做 Step 0 摸清基线。
- **坑 9**:平台已有的组件/色板重新发明一遍 → **能继承的绝不自造**,行业增量只加在平台留的自定义区间。
