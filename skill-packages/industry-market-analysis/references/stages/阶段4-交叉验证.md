# 阶段 4 · 交叉验证

> 承上启下的"质检关卡"。前两阶段(外部调研 + 京东内诊)攒了一堆数字和结论,本阶段把不可靠的挑出来:能双源印证的留、只有单源的标、互相矛盾的存疑。**这一关不过,后面的机会合成就是建在流沙上。**

## 目标

用 0.5-1 天(轻档 1-2 小时),给阶段 2-3 产出的**每个量化数字和关键结论**做可信度分级,产出一张"数据可信度台账",并同步开始搭建附录 I(方法论与数据源清单)。

## 前置输入

- 阶段 2 的 `行业报告/数据摘录.md`、`竞品分析.md`
- 阶段 3 的 `京东内诊报告.md`(含 KPI、舆情)
- 各处散落的引用 URL 和数据源

## 具体动作

### Step 1 · 把所有量化断言列成台账(30-60 分钟)

翻出前两阶段所有的 `%`、`¥`、`增速`、`排名`、`占比`,以及"头部集中""增长最快"这类**隐含量化的结论**,逐条填入台账 `数据可信度台账.md`:

```markdown
| # | 断言 | 数字 | 现有来源 | 来源数 | 时间口径 | 状态 |
|---|---|---|---|---|---|---|
| 1 | 品类市场规模 | ¥X 亿 | 艾瑞 2024 | 1 | 2024 全年 | 待补源 |
| 2 | 线上占比 | X% | 开卷 + 亿邦 | 2 | 2024 | ✅ 已验 |
| 3 | 头部集中度 CR5 | X% | 无,凭印象 | 0 | — | ⚠ 存疑 |
```

**避坑**:别只列"明显是数字"的。"最大""领先""普遍"这类词也是量化断言,同样要有依据。

### Step 2 · 三级分级验证

对台账每一条,按下面规则定状态。验证强度按档位递减(见三档差异):

#### ✅ 已验(可直接用)

- **标准**:≥2 个独立来源,数字一致或差异 <15%
- 独立 = 不同机构、不同调研方法(两家都转引同一个源 ≠ 双源)
- 动作:保留,正文可直接引用

#### 待补源(单源,需标注)

- **标准**:仅 1 个来源,但来源权威(艾瑞/QuestMobile/开卷/官方等)
- 动作:保留,但正文引用时标"(单源:XX)",尽量再找第二源

#### ⚠ 存疑 / 估算(必须标记)

- **标准**:无来源、来源不可考、多源互相矛盾且无法判断
- 动作:要么删掉,要么改写为"**估算·待核实**",绝不裸用

**判断多源矛盾时**:优先取(a)时间更近、(b)口径更清晰、(c)机构更权威的。三者冲突时并列展示分歧,不强行取一个。

### Step 3 · 处理矛盾数据(重点)

遇到两个源打架,别慌,按此流程:

```
两个数字矛盾
  ↓
口径是否相同?(如"市场规模"是含二手/不含二手?线上/全渠道?)
  ├─ 口径不同 → 不是矛盾,是两个不同指标,分别标注
  └─ 口径相同 → 比时间、比权威、比方法
        ↓
     仍无法判断 → 正文并列展示:"X 亿(艾瑞)/ Y 亿(QuestMobile)"
```

**避坑**:很多"矛盾"其实是口径不同(全渠道 vs 线上)。先对齐口径,再谈矛盾。

### Step 4 · 验证京东内诊的推测

阶段 3 的问题清单里有很多"推测"(如"推测拉高跳出率")。这些定性推测也要标可信度:

- **有数据支撑**(如真拿到跳出率数据)→ 升级为"已验证问题"
- **纯体验推测** → 保留,但在报告里措辞为"推测/可能",不写成事实
- **能小成本验证的** → 记入阶段 8 的"前置假设"待验证清单

### Step 5 · 同步搭建附录 I 骨架

验证过程中,数据源信息是现成的,顺手把附录 I 的数据源清单搭起来(存 `附录I-方法论草稿.md`),阶段 7 直接拿来用:

```markdown
## 数据来源清单(草稿)

**行业数据源**:
- 艾瑞《XX 报告》,发布 2024-XX,URL:...
- 开卷《XX》,发布 2024-XX

**竞品截图时间**:
- 淘宝 XX 频道,2026-XX-XX
- ...

**内部数据**:
- 京东 XX,周期 2026-XX(或"未获取")

**已知局限**(边验边记):
- 共 X 条数据为单源,未双验
- 共 X 条标"估算·待核实"
```

**这一步是"顺手做",不额外花时间**——你正在看每个数据的来源,记下来就是附录。

```
以下是我从行业调研里摘出的所有量化数字和关键结论:
{粘贴阶段 2-3 的数字和结论}

请帮我整理成"数据可信度台账"表格,列:断言 / 数字 / 现有来源 / 来源数 / 时间口径。
并对每条初步判断状态:✅已验(≥2独立源)/ 待补源(单权威源)/ ⚠存疑(无源或矛盾)。
凡是"最大""领先""普遍"这类隐含量化的词,也要列进去。
```

### 帮我判断数据是否矛盾

```
我拿到两个关于「{品类}市场规模」的数字:
- 来源 A:{数字 + 口径 + 时间 + 机构}
- 来源 B:{数字 + 口径 + 时间 + 机构}

请判断:这是真矛盾,还是口径不同导致的伪矛盾?
如果口径不同,分别说明各自测的是什么。
如果口径相同确实矛盾,建议正文怎么处理。
```

### 帮我审一遍哪些结论下得太满

```
以下是我京东内诊报告里的问题结论:

请挑出其中"证据不足却写得像事实"的结论,建议改成"推测/可能"的措辞。
另外指出哪些结论可以用小成本方式验证(如埋点、5 人快速测试),
这些我要放进"前置假设待验证清单"。
```

## 三档差异

| 项 | 轻档 | 中档 | 重档 |
|---|---|---|---|
| 验证范围 | 前 3 条头条数据 | 全部量化断言 | 每个数字必带出处 |
| 双源要求 | 头条数据尽量双源 | 关键数据双源 | 所有核心数据双源 |
| 矛盾处理 | 存疑即标注 | 对齐口径后判断 | 逐条溯源+并列展示 |
| 附录 I | 简版数据源 | 数据源清单 | 完整方法论+局限 |
| 内诊推测验证 | 措辞降级即可 | 标推测+列可验证项 | 小成本实测部分假设 |

## 自检清单

- [ ] 所有 `%`/`¥`/增速/排名 都进了台账(含"最大/领先"等隐含量化词)
- [ ] 每条断言标了状态(✅已验 / 待补源 / ⚠存疑)
- [ ] "估算·待核实"的数量 < 总量的 20%
- [ ] 矛盾数据已先对齐口径,再判断真伪
- [ ] 头条数据(报告最显眼的几个数字)已尽力双源
- [ ] 京东内诊的纯推测已降级措辞(推测/可能)
- [ ] `附录I-方法论草稿.md` 已同步搭建

## 常见坑

- **坑 1**:只验明显的数字,漏掉"最大/领先/普遍"这类隐含量化断言 → **它们同样需要依据**。
- **坑 2**:把"两家都转引艾瑞"当双源 → **不是独立源**。独立 = 不同机构+不同方法。
- **坑 3**:看到两个数字不一样就判"矛盾" → **先对齐口径**,很多是全渠道 vs 线上的伪矛盾。
- **坑 4**:存疑数据舍不得删,裸用在正文 → **要么删,要么标"估算·待核实"**,裸用会毁掉报告可信度。
- **坑 5**:交叉验证和搭附录分两次做 → **验证时来源就在眼前,顺手记进附录**,别做两遍。
- **坑 6**:把内诊的体验推测写成既定事实 → 证据不足的一律"推测/可能",能验的进假设清单。
