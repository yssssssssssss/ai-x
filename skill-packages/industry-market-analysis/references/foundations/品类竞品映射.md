# 品类竞品映射

> 每个品类要看哪些竞品/参考,给个候选清单,避免每次都从 0 想。四分组:直接竞品 / 内容工具类 / 跨行业 / 海外。用于阶段 2 外部调研。

## 使用方法

1. 找到你要做的品类
2. 从每组各选 2-4 家(不必全)
3. 手动截屏或用 WebFetch 抓取,进入阶段 2 分析
4. 每家用 `模板/对比表-四要素.md`(核心特征/适配场景/优点/局限)拆解
5. 如果你的品类不在此清单,自己按 4 组模板补,并把结果反馈回本文件迭代

## 选竞品的 4 条原则

1. **直接竞品选 3 家,不要更多**。老大、老二、暗流者(如拼多多、抖音)。
2. **内容参考要跨形态**。社区型(小红书/豆瓣)、工具型(什么值得买)、专业媒介型(中关村/汽车之家)各选一个。
3. **跨行业专挑机制**。不看画面,看它解决了什么问题:决策辅助?氛围感?榜单信任?忠诚度?
4. **海外看结构而非功能**。海外优秀案例常有更成熟的信息架构或商业模式,别抄细节抄骨架。
