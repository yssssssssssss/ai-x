# 竞品分析 · 6 板块

> 把竞品分析从"一张四要素表"升级为完整流程:**选样 → 多维对比 → 心智提炼**。用于阶段 2(竞品拆解)独立成章,也是 HTML 报告"竞品分析"Tab 的内容骨架。
>
> 三段式流程:
> ```
> 选样(谁值得比)  →  多维对比(比什么、怎么比)  →  心智提炼(占了什么位、空白在哪)
>   ①②                    ③④                          ⑤
>                                                    ⑥ 采集清单贯穿支撑
> ```

## 6 板块速览

| # | 板块 | 阶段 | 一句话作用 |
|---|---|---|---|
| ① | 选样与分组 | 选样 | 说清"选谁比、为什么选",四组各 2-4 家 |
| ② | 四要素全景总览 | 选样 | 每家一行的横向总表(核心特征/适配场景/优点/局限) |
| ③ | 商业逻辑对比 | 多维对比 | 赚钱方式 / 售卖模式 / 选品逻辑,横向比 |
| ④ | 体验设计对比 | 多维对比 | 信息架构 / 交互 / 视觉 / 决策链路,横向比 |
| ⑤ | 心智定位 + 二维象限图 | 心智提炼 | 各家占据的心智,象限图找空白 |
| ⑥ | 证据采集清单 | 支撑层 | 每家要采哪些截图/数据/URL,保证结论可追溯 |

**做减法原则**:轻档只做 ①②⑤(选样+总览+象限);中档加 ③④;重档全上 + 每格带证据编号回指 ⑥。

## ① 选样与分组

> 竞品分析第一错是"选样错":选了不可比的、漏了真对手。先说清选谁、为什么。

沿用 `参考资料/品类竞品映射.md` 的四分组,每组选 2-4 家,并写一句**入选理由**。

```markdown
### 选样与分组

| 分组 | 竞品 | 入选理由(为什么值得比) |
|---|---|---|
| 直接竞品 | {老大} | 品类份额第一,基准线 |
| 直接竞品 | {老二} | 差异化打法参照 |
| 直接竞品 | {暗流者,如拼多多/抖音} | 低价/内容侧的冲击者 |
| 内容/工具 | {社区型} | 看它怎么建氛围/信任 |
| 内容/工具 | {工具型} | 看它怎么做决策辅助 |
| 跨行业 | {机制参照} | 借它的{决策辅助/榜单/忠诚度}机制,不看画面看骨架 |
| 海外 | {结构参照} | 借它更成熟的信息架构/商业模式 |
```

**避坑**:直接竞品别超 3 家(老大+老二+暗流者足够);跨行业选"机制"而非"同行"。

## ② 四要素全景总览

> 原"四要素表"在这里作**总览**:一眼看全所有样本的定位。四要素固定:核心特征 / 适配场景 / 优点 / 局限。详细写法见 `模板/对比表-四要素.md`。

```markdown
### 四要素全景总览

| 竞品 | 核心特征 | 适配场景 | 优点 | 局限(对我方启发) |
|---|---|---|---|---|
| {竞品 A} | ... | ... | ... | ... |
| {竞品 B} | ... | ... | ... | ... |
| {竞品 C} | ... | ... | ... | ... |
```

**要点**:局限一列尽量写成"对我方的启发"(它没做好的=我方机会),直接喂给板块 ⑤ 找空白。

## ③ 商业逻辑对比

> 竞品**靠什么赚钱、怎么卖、卖什么**,横向比。对应维度 J。每格尽量落到"对设计意味着什么"。

```markdown
### 商业逻辑对比

| 竞品 | 赚钱方式 | 售卖模式(货架/直播/内容占比) | 选品逻辑 | → 对设计的启发 |
|---|---|---|---|---|
| {竞品 A} | {差价/佣金/广告/会员} | {以直播为主} | {爆款优先} | {入口/卡片形态} |
| {竞品 B} | ... | ... | ... | ... |
| 我方(京东) | ... | ... | ... | ... |
```

**要点**:把"我方"作为最后一行放进对比,商业差异一眼可见;每行末列强制回答"这条商业逻辑该怎么影响一个设计决策"。

## ④ 体验设计对比

> 竞品**体验怎么做**,横向比。四个子维度:信息架构 / 交互模式 / 视觉语言 / 决策链路。这是设计师最高频看的一张表。

```markdown
### 体验设计对比

| 竞品 | 信息架构 | 交互模式 | 视觉语言 | 决策链路(如何帮用户下决心) |
|---|---|---|---|---|
| {竞品 A} | {首页几屏/几个入口} | {弹窗多不多/打断} | {主色/卡片风格} | {评价/榜单/达人 哪个撑决策} |
| {竞品 B} | ... | ... | ... | ... |
| 我方(京东) | ... | ... | ... | ... |
```

**要点**:决策链路一列最关键——它直接对接体验诊断的"决策链路"类问题。看竞品用什么撑决策(评价?达人?榜单?),反推我方缺什么。

## ⑤ 心智定位 + 二维象限图

> 竞品分析的**收口**:每家占了用户心里的什么位置,画二维象限图,找到没人占的空白 = 我方差异化机会。

### 5.1 心智定位表

```markdown
| 竞品 | 一句话心智(用户会怎么描述它) | 占据的价值 |
|---|---|---|
| {竞品 A} | "买{品类}最{便宜/全/潮}的地方" | 低价 / 齐全 / 潮流 |
| {竞品 B} | ... | ... |
| 我方(京东) | {当前心智 vs 目标心智} | ... |
```

### 5.2 二维象限图(找空白)

**选轴原则**:两条轴要**正交**(彼此独立),且能把竞品拉开距离。常用轴:

- 价格心智(低价 ↔ 高信任/高端)
- 交易属性(货架交易 ↔ 内容陪伴)
- 专业度(泛综合 ↔ 垂直专业)
- 服务深度(纯卖货 ↔ 全生命周期服务)

选一对能露出"空白象限"的轴。把每家竞品作为一个点标在图上,**空的那一格就是机会**。

```
                  ↑ {Y 轴高:如 内容陪伴}
                  │
       {竞品}     │      {竞品}
                  │
  {X轴低}─────────┼─────────→ {X轴高:如 高信任}
                  │
       {竞品}     │   ★我方目标位(空白)
                  │
                  ↓ {Y 轴低:如 货架交易}
```

**要点**:
- 象限图是**汇报最有冲击力的一张图**,务必让"我方目标位"落在一个相对空白的象限。
- 若我方目标位和某竞品重叠,说明差异化没想清——回板块 ③④ 重找差异点。
- 一句话结论收口:"{低价}被 X 占、{内容}被 Y 占,我方空间 = {某象限}。"

## ⑥ 证据采集清单

> 支撑层:上面 5 个板块的每个结论,都要能回指到一份证据。列清单保证"竞品分析不是拍脑袋"。

```markdown
### 证据采集清单

| 竞品 | 要采的证据 | 类型 | 状态 |
|---|---|---|---|
| {竞品 A} | 首页首屏+下滑2屏、榜单页、详情页评价区 | 截图 ×3 | ☐待采/☑已采 |
| {竞品 A} | 市场份额/GMV | 数据+URL | ☐ |
| {竞品 B} | ... | ... | ☐ |
```

**采集原则**(对齐阶段 2):
- 每家至少 3-5 张关键页截图(首页/榜单/详情/下单),每张记 1 句观察
- 每个量化数字带 URL 或标"待核实"
- 板块 ③④⑤ 里每个论断,尽量在末尾标证据编号(如 `[A-截图2]`),做到可追溯

## 常见误区

- **误区 1**:6 板块全写满 → 轻档只做 ①②⑤。板块是"可选深度",不是"必填项"。
- **误区 2**:③④ 里不放"我方" → 必须把京东作为最后一行,否则对比没有落点。
- **误区 3**:象限图两轴选得不正交(如"价格"vs"性价比")→ 两点连成一条线,看不出空白。选正交轴。
- **误区 4**:心智定位写成"功能罗列" → 心智是"用户一句话会怎么描述它",不是功能清单。
- **误区 5**:结论没证据回指 → 竞品分析最易被质疑"你怎么知道",⑥ 就是用来防这个的。
