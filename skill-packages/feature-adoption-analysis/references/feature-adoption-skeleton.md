# 功能采纳诊断 · 输出骨架与模板

> 本文件是 **feature-adoption-analysis skill 自己的产出结构**，不是 wiki 正典。四段漏斗划分、五维指标公式、分段病因、cohort 做法、行业基准等正典内容**一律运行时从 `research-wiki/methods/toolbox/analysis/feature-adoption.md` 现读**（见 SKILL.md 第 2 步），不在此复制。
> 方括号 `[…]` 是占位槽，按本批数据与读到的正典填实；列名/口径**以运行时读到的正典为准**。**只输出本次实际做到的块**，没做的不强行凑。
> **两条硬约束**：① **每个采纳率/段转化率/人数/留存% 必须从给定数据真算**，没真算的绝不写一个看似精确的数（SKILL 纪律 4）。② **分层：发现层写干净、能扫读；算力声明、口径存疑、draft、相关≠因果这些依据与边界集中到文末**（SKILL 北极星「分层交付」），别逐句夹进发现里。

# 一、直接分析模式 · 输出骨架

> 结构 = 顶部一行 caption → **【发现层】**（结论摘要→漏斗→指标→留存→病因→建议，写干净）→ **【依据与边界层】**（数据与口径说明→自检→运行说明）。

**顶部 caption（一行，不展开）**
```
> 功能=[X] ｜ 目标=[效果评估/流失诊断/去留判断] ｜ 数据=[分段漏斗/cohort/仅总量] ｜ 激活=[定义]（[用户给定/本skill建议待确认]）｜ cohort=[有/无]
```

## 【发现层】

### 0. 采纳诊断结论摘要（结论先行，放最前）

> 加粗一句话判断 + 3–4 条关键发现要点 + Top 建议。**别写成一大段**；先给答案，再给数。

```
**一句话判断**：[这次迭代基本被接住/没被接住——最大流失卡在「[某段]」（[x%]），最可能是[病因]；建议[继续补X/收缩/下线]。]

**关键发现**
- 漏斗：曝光[n]→激活[n]（[%]）→使用[n]（[%]）→复用[n]（**[%]，最低**）
- 最该盯：[某段] —— [一句为什么]
- [一条留存/指标要点，如有]

**Top 改进建议**
1. [针对某段] → [改进动作] → [怎么回测]
2. …
```

### 1. 采纳漏斗

```
| 漏斗段 | 人数 | 段转化率(本段/上段) | 备注 |
|---|---|---|---|
| 曝光/触达 | [n1] | —— | [分母口径] |
| 激活 | [n2] | [n2/n1] | —— |
| 使用 | [n3] | [n3/n2] | —— |
| 复用 | [n4] | [n4/n3] | 🔴[若最低→最大流失段/最值得警惕] |

最大流失段：**[某段]**（[z%]，全漏斗最低）。[某段无数据→留空标"该段无数据"，不脑补。]
```

### 2. 五维采纳指标

> 表格一张说清；"是否实算"用一列区分，**不在正文另起段落重复解释未实算**（系统性口径下沉到文末⑦）。

```
| 指标 | 取值 | 是否实算 | 一句话 |
|---|---|---|---|
| 采纳率 | [x% / —] | [✅/❌需分母] | 分母=[同期登录/目标分群] |
| 采纳广度 | [x% / —] | [✅/❌] | —— |
| 深度/频率 | [x次/人 / —] | [✅/❌] | ⚠️高频需分刚需vs反复试错 |
| 首次采纳时间 | [—] | ❌需时间戳 | —— |
| 功能留存 | [见下/—] | [✅/❌需cohort] | —— |
```

### 3. 功能留存 / cohort（可选，有 cohort 才做）

```
| 批次 | 第0周 | 第1周 | 第2周 | 第4周 | … |
|---|---|---|---|---|---|
| [A] | 100% | [%] | [%] | [%] | |

读法：[快速衰减→一时新鲜 / 趋平台期→形成习惯]。无 cohort → 一句"无按批次时间序列，留存曲线未做，建议按周对齐版本采集"。
```

### 4. 最大流失段病因（先给最可能的一个）

> **一个主假设**说透，其余"其他可能"一笔带过；配一句怎么验证。别把三四个并列假设＋机理长篇堆在这里。

```
**[某段]（[z%]）最可能的病因**：[主假设，措辞"最可能/疑似"]——[一句机理，如复用低=价值/习惯未形成，可引 ECT 期望-感知落差]。
其他可能：[次假设1] / [次假设2]（一句带过）。
怎么验证：对[该段人群]做[分段问卷/访谈/VOC]，问"[具体场景化问法]"。⚠️病因是假设，改动需 A/B 或下期回测（相关≠因果）。
```

### 5. 迭代建议 + 回测

```
| # | 针对段/病因 | 改进动作 | 回测方式 |
|---|---|---|---|
| 1 | [复用/价值] | [价值传达/习惯钩子/召回] | [下期留存曲线 或 A/B] |
| 2 | [激活/摩擦] | [降摩擦/提前啊哈] | [激活段转化率 A/B] |
（需排序则叠加 issue-prioritization 排 P0/P1/P2。）
```

### 6. 数据与口径说明

> 把方法论交代与算力声明**集中在这里**（不要放在文档开头、也不要拆散夹进各发现）。

```

- 采纳率分母：[同期登录/目标分群/待确认]
```

# 二、工具包模式 · 输出骨架（无采纳行为数据时）

> 末尾必须**明确索要采纳行为数据**：拿到后即可切到直接分析。

**1. "激活"事件定义建议**
```
- 功能：[X]｜建议激活=[价值型动作，如"成功用该功能完成一次有意义任务"]（待确认）
- 为何不能拿点击/打开当激活：[会让采纳率虚高、留存惨淡]
```
**2. 四段漏斗埋点方案**
```
| 段 | 埋什么事件 | 记录字段 |
|---|---|---|
| 曝光/触达 | [公告曝光/入口进入/浮层展示] | 用户ID·版本号·时间戳 |
| 激活 | [价值型激活动作] | 同上 |
| 使用 | [完整完成一次任务] | 同上 |
| 复用 | [回来再次使用] | 同上 |
> 口径一致、记版本号与时间戳，才能跨版本对齐、支撑 cohort。
```
**3. 五维指标口径清单**：采纳率(含分母口径)/广度/深度频率/首次采纳时间/功能留存，各口径运行时从正典现读、别默写。
**4. cohort 分群设计**：按新老/版本/渠道/价值分层；用户级+账号级两级都看；先剔除机器/自动事件与非目标角色再算分母。
**5. 数据索要清单**：① 分段人数漏斗或埋点事件明细 ② 价值型激活定义 ③（判留存则）按批次 cohort 表 ④ 采纳率分母口径。
**6.《本次运行说明》**（五部分）。

# 五、形态示意（仅示范「长什么样」，**勿照抄内容**——按真实数据重写）

> 下例是凭空编的格式演示，不是正典内容、不是真实数据。注意它如何：**结论先行、发现写干净、病因先给一个、口径与算力集中到文末**。

```
> 功能=一键复购 ｜ 目标=效果评估+流失诊断 ｜ 数据=分段漏斗(无cohort) ｜ 激活=完成一次一键复购下单(用户给定) ｜ cohort=无

## 采纳诊断结论摘要
**一句话判断**：一键复购前段能拉起，但没被接住——最大流失卡在「使用→复用」（25%），最可能是复购价值没兑现/没形成习惯；建议先做复用召回并回测，暂不下线。
**关键发现**
- 漏斗：曝光8000→激活4000(50%)→使用2400(60%)→复用600(**25%，最低**)
- 最该盯：使用→复用段，正典称其为"最值得警惕"
- 采纳率因缺分母未实算（见文末口径）
**Top 改进建议**
1. 复用/价值 → 结果页突出"更省事"的复购价值 + 召回 → 下期该cohort留存曲线 或 A/B

## 采纳漏斗
| 段 | 人数 | 段转化率 | 备注 |
|---|---|---|---|
| 曝光 | 8000 | —— | 分母=同期登录 |
| 激活 | 4000 | 50% | |
| 使用 | 2400 | 60% | |
| 复用 | 600 | 🔴25% | 最大流失段 |

## 最大流失段病因
使用→复用(25%)最可能：复购价值未兑现（用一次觉得没更省事）。其他可能：需求本低频 / 入口想不起来。怎么验证：访谈"用过一次没再用"的人问"上次复购后为什么没再用"。⚠️病因是假设，需 A/B 回测。

## 数据与口径说明
- 数据形态：分段漏斗；直接分析。激活=用户给定价值型动作 ✅。
- 采纳率分母：曝光8000≠同期登录，未按口径实算；请补同期登录数。
- 算力声明：段转化率50/60/25%真算；采纳率/留存/深度未实算（无分母/无cohort/无次数）。
- 机器事件：未知是否剔除，激活可能虚高。
（自检、运行说明略）
```

> 注意上例：结论段没有夹算力声明；口径与"未实算"集中在文末「数据与口径说明」；病因只给一个主假设 + 一句其他可能。**形式照此，内容按真实数据重写。**
