# 阶段 7 · 品类差异资产

> 覆盖 G 维度的**落地延伸**。阶段6 把"该做什么"推导到"长什么样(色板/气质)"就停了;本阶段继续往下,把设计语言延伸为**可复用、可更新的「品类差异资产」**——沉淀该品类的视觉基因/文案语气/玩法/动效及行业标杆,让下次做该品类的互动运营时,不必每次从零收集判断。
>
> **核心信条**:资产库只沉淀"品类差异化"的东西,不碰"平台统一"的东西。判断尺子——**平台统一的不进(不和规范抢活),品类差异化的才进(频道主场)**。

## 为什么要这个阶段

行业分析不该是"一次性报告"。团队日常固定盯着几个品类频道(如超市/数码/图书/宠物/美妆/家居/校园),每次做互动运营(签到/答题/子频道等)都要重新判断"什么视觉、玩法、动效符合品类心智",重新收集行业参考——这是最大的重复劳动。

**资产库把这份判断沉淀下来**:一次调研 → 沉淀成带判断的参考 → 下次直接查,并可随行业变化定期更新。它是行业分析这条生产线的**累积产物**,做的品类越多、库越厚。

## 目标

用 0.5-1 天,在阶段6 设计语言之上,产出该品类的**品类差异资产**(五段),每条资产带判断依据与保鲜字段,可直接支撑该品类的互动运营设计,并能随行业调研迭代更新。

## 前置输入

- **阶段6 的设计语言推导**(品类属性→气质→色板)—— 资产库的推导起点,①心智锚点②视觉基因直接继承
- **阶段2 的竞品截图/调研** —— 行业标杆的来源
- **阶段3 的内诊** —— 该品类现状里"哪些已有书味/哪些通用化",正向反向参考都有用
- **平台基线**(`参考资料/京东设计哲学(平台基线).md`)—— 判断"哪些该归平台不进库"

## 判断尺子:什么进库,什么不进

**先用这把尺子过一遍,避免和平台规范/其他团队抢活:**

| 类型 | 例子 | 进库? |
|---|---|---|
| 平台已统一/规范覆盖 | 基础组件、弹窗规范、加购收藏、骨架屏、IP(用平台统一) | ❌ 不进(继承平台) |
| 通用电商形态 | 通用分类页、通用促销页 | ❌ 不进(那是通用件) |
| **品类差异化的心智表达** | 品类特色玩法、品类图形、品类动效性格 | ✅ **进库(频道主场)** |
| 平台未细化到的品类留白 | 品类装饰图形/母题纹样(平台可能定了图标系统,但不会细化到品类纹样) | ✅ 进库 |

> **坑**:别把"通用高频"的东西放进库——凡"通用+高频+标准"的,平台设计系统迟早会覆盖(那是它的天职),放进来就是重复造轮子。库的价值在"差异化",不在"通用"。

## 五段结构(固定)

每个品类档案固定五段。前两段继承/延伸阶段6,后三段是本阶段的落地延伸:

| 段 | 内容 | 来源 |
|---|---|---|
| **① 心智锚点** | 一句话总锚点 + 3-4 个心智支点(每个展开:内涵→对设计的要求→落地抓手)+ 气质/定位 | 继承阶段6,展开到可落地 |
| **② 视觉基因** | 色板(**带 hex + 继承/增量,色板唯一权威位置**)· 字体倾向 · 质感 · **图形母题/装饰纹样** · **品类特有信息呈现范式**(如图书=书单卡/专业榜单维度) | 继承阶段6 + 延伸(图形、静态呈现范式都归这里;色板只在这段给完整值,推导链不重复列) |
| **③ 文案语气** | 品类的"说话方式":推荐语/按钮/空状态/签到文案的语气与用词倾向(如图书=有书卷气、编辑化、陪伴感,忌大促叫卖) | 新延伸(品类心智的文字载体) |
| **④ 玩法基因** | 品类适配的互动玩法(含✗不适配的反例) | 新延伸(核心) |
| **⑤ 动效性格** | 动效性格 + 关键场景 + 质感运动 | 新延伸(承接16.0动效规范) |

> **合并说明**:原「图形资产」并入②视觉基因(图形母题本就是视觉元素,单列会与"质感"打架);原「呈现资产」拆解——**信息呈现范式**(书单卡/榜单维度这种可复用的品类结构)并入②视觉基因,**具体设计方案**(如"分类页导购升级 P0-3")不进资产库、回「设计策略」Tab(那是一次性机会,不是可复用资产)。
> **质感**不单开段,作为②视觉基因(静态质感)和⑤动效(质感运动)的属性。**IP/通用结构不进库**:IP 用平台统一、通用结构继承平台规则。
> **资产库 vs 设计策略的界线**:资产库放**"可复用、跨需求的品类设计语言基因"**(这个品类该长什么样/说什么话/玩什么);具体某个页面怎么改(带 P0 编号的方案)属于设计策略,不进库。

## 每条资产的字段规范(必填)

每条资产不是一句话,而是一个带判断、带保鲜的结构。**带 ★ 的字段是关键**:

```
一条资产:
  · 名称
  · ★ 适配度:✓✓强推 / ✓可选 / ✗不合适   ← 让下次能直接取舍
  · ★ 为什么(判断灵魂):为什么适合/不适合这个品类的心智   ← 让参考带判断,而非素材堆
  · 行业标杆:谁做过、做得好不好(截图/链接/描述)
  · ★ 采集时间 + 来源                        ← 保鲜:知道多久了、依据什么
  · ★ 复盘状态:最新已核 / 待复盘 / 已过时      ← 保鲜:一眼看出哪些该更新
```

- **适配度 + 为什么**:让库"带判断",下次做设计直接看✓✓/✗和理由就能取舍,不用重新收集判断。
- **保鲜字段**:让库"能新陈代谢",不是死档案。

## 具体动作

### Step 1 · 继承阶段6 + 视觉基因(①②段,30分钟)
①心智锚点:先用一句话立总锚点(这个品类频道要让用户感到"这是一个怎样的地方"),再把品类属性拆成 **3-4 个可落地的心智支点**,每个支点展开成一张表的一行:**内涵(用户心里在想什么)→ 对设计的要求 → 落地抓手(具体玩法/视觉/组件)**。气质词/定位放末尾做小字补充。**别只平铺"属性·气质·定位"三组抽象词——那样等于没说,必须展开到"设计该往哪使劲"**。
②视觉基因:色板/字体填入,补"质感"(如图书=纸纹/书页阴影);**并入图形母题/装饰纹样**(如图书=书签/藏书章/纸纹;宠物=爪印/骨头;美妆=花瓣)——只列平台不会细化到的品类专属图形,通用图标归平台;**再列品类特有的信息呈现范式**(如图书=书单专题卡/专业榜单维度这种可复用结构),通用布局继承平台不做。

### Step 2 · 文案语气(③段,20分钟)
定义该品类的"说话方式":推荐语/按钮文案/空状态/签到提示的**语气倾向与用词**。给正向示例 + 反向禁忌(如图书=编辑化荐书语、陪伴感,✗大促叫卖式"抢""秒杀")。配行业标杆(如多抓鱼"店员日记"、微信读书陪伴文案)。文字是品类心智最直接的载体,别漏。

### Step 3 · 玩法基因(④段,核心,45分钟)
列该品类高频互动玩法(签到/答题/收集/养成/抽奖…),逐个判断适配度(✓✓/✓/✗)并写"为什么"。**尤其要标出✗不合适的**(如图书=暴力抽奖✗,与专业书卷心智冲突)——反向判断和正向一样有价值。配行业标杆。

### Step 4 · 动效性格(⑤段,30分钟)
定义该品类的**动效性格总纲**(节奏快慢/曲线软硬/隐喻,如图书=沉稳/纸感/翻阅隐喻),列关键动效场景的品类化处理。**每条要在平台动效规范框架内生长**——先归类到"物理类(弹簧)/经典类(缓动)"、定 Z 轴层级(高=稳/低=灵动)、按面积法则与"进出场不对称"定时长方向;**具体参数(时长各档 ms/缓动曲线值/弹簧阻尼)回原文查、别自己拍数**。框架与来源见 `参考资料/京东设计哲学(平台基线).md` 的「四·附、动效规范」。

### Step 5 · 加保鲜字段(10分钟)
给整个库标采集时间、来源;每条(或每段)标复盘状态。首版统一标"待复盘"。

## 活库更新机制(让库不死)

资产库是**活的**,不是一次性攒完:

- **更新触发**:定期(每季度)或事件驱动(该品类要大改版、出现明显新趋势时);
- **更新动作**:用本 skill(阶段2 竞品调研)重扫该品类竞品,对比库里旧资产 → 保留 / 更新 / 淘汰 / 新增,并更新"复盘状态";
- **这是团队的独特优势**:营销大促等团队做通用工具,不会持续盯单个垂类;而事业部频道团队日常深耕这几个频道,"持续更新的品类库"只有你们做得成。

## 产出物

- `品类差异资产.md`,含五段,每条资产带完整字段(适配度/为什么/标杆/保鲜)。
- 渲染进 HTML 报告时,**作为第 5 个 Tab「品类差异资产」**,阶段6 的设计语言推导移到该 Tab 开头作为"推导起点"(见 `阶段说明/阶段8-报告装配与自检.md`)。

## 三档差异

| 项 | 轻档 | 中档 | 重档 |
|---|---|---|---|
| 段数 | ①②④(心智/视觉/玩法) | 五段全 | 五段全 + 每段更多条目 |
| 每条字段 | 适配度+为什么 | 全字段 | 全字段 + 多个行业标杆截图 |
| 玩法条目 | 3-4 个 | 5-6 个 | 8+ 个,含✗反例 |
| 动效 | 性格总纲一句 | 关键场景表 | + 具体曲线/时长参数 |

## 自检清单

- [ ] 每条资产都用**判断尺子**过滤了(平台统一的没进库)
- [ ] 五段齐全(轻档至少①②④玩法),IP/通用结构没进库
- [ ] 每条玩法都有**适配度 + 为什么**,且**至少标出 1 个✗不合适**(反向判断)
- [ ] 每条资产有**行业标杆**(截图/链接/描述)
- [ ] ⑤动效每条归到平台动效规范框架(物理/经典类 + 层级 + 面积/进出场法则);精确参数回原文查、没自己编 ms/曲线值
- [ ] ②视觉基因里图形母题只收"平台未细化的品类专属图形",通用图标没进;信息呈现范式只收可复用结构,具体方案(带P0编号)没混进来
- [ ] 全库有**保鲜字段**(采集时间/来源/复盘状态)
- [ ] ①②段与阶段6 一致(不重新推导,直接继承)
- [ ] **①心智锚点已展开到可落地:一句话总锚点 + 3-4 个心智支点(每个含"内涵→对设计的要求→落地抓手"),不是只平铺"属性·气质·定位"三组抽象词**

## 常见坑

- **坑1**:把通用高频的东西(弹窗/加购/骨架屏)放进库 → 平台迟早覆盖,重复造轮子。**用判断尺子过滤**。
- **坑2**:资产只有截图没有判断("某App做了个签到") → **必须带适配度+为什么**,否则下次还得重新判断,等于没沉淀。
- **坑3**:只收✓的、不收✗的 → **✗不合适+为什么**同样有价值,帮下次直接排除。
- **坑4**:动效脱离平台自由发挥 → **必须标16.0约束**,品类表达在规范内生长。
- **坑5**:库建完就不管了 → **是活库**,要标复盘状态、定期用skill重扫更新。
- **坑6**:IP/通用结构也想沉淀 → IP用平台统一、结构继承平台,不进库。
