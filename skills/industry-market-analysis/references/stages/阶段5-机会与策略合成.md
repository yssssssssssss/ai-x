# 阶段 5 · 机会与策略合成

> 覆盖 F(机会与策略)维度。前四阶段是"输入",本阶段是**第一次真正的"输出"**:把用户痛点、竞品做法、京东现状三方一撞,撞出"该做什么、凭什么做、先做什么"。这是全报告最能体现你判断力的一章。

## 目标

用 0.5-1 天,产出三件事:
1. **Gap 矩阵**——用户要什么 × 京东有什么 × 竞品给什么,空白在哪
2. **差异化定位**——京东在本品类"是什么、不是什么"的一句话
3. **机会清单 + 三档优先级**——打分排序后的短/中/长期动作

## 前置输入

- 阶段 3 `京东内诊报告.md`(京东现状与问题,**每条问题已挂钩违反的平台设计原则**)
- 阶段 2 `竞品分析.md`(竞品供给,6 板块的④体验对比 + ⑤心智象限)
- 阶段 2 的用户痛点 / 阶段 1 的核心问题(用户诉求)
- J 商业与经营逻辑(阶段 2 外部 + 阶段 3 京东):**机会要接住商业逻辑**,别提用户想要但商业上不成立的机会
- 阶段 4 已验证的可信结论(**只用验过的,存疑数据不进推导**)
- `参考资料/京东设计哲学(平台基线).md`——定位与机会的价值观锚点
- 模板:`模板/优先级表-三档分期.md`

> **诊断→策略的回接**:阶段 3 每条问题都标了"违反平台原则【X】"。到本阶段,**"让频道回到平台原则 X"本身就是一类机会来源**——把违反最严重的原则,翻译成 Gap 矩阵里的用户诉求行。这样策略不是凭空长出来的,而是"把偏离平台标准的地方补回来 + 在此之上做行业增量"。

## 具体动作

### Step 1 · 搭 Gap 矩阵(45 分钟)

把三方并排放,找空白。每行一个用户诉求:

```markdown
| 用户诉求 | 京东现状 | 竞品供给 | Gap 等级 |
|---|---|---|---|
| 快速找到"值得买的" | 榜单信息过载 | Amazon 有评分+评论决策辅助 | ★★★ |
| 送礼场景选购 | 无礼品专区 | 淘宝有礼品卡+场景导购 | ★★ |
| 沉浸式了解商品 | 详情页信息堆砌 | 小红书有种草内容 | ★★ |
```

**Gap 等级怎么定**:
- ★★★ = 用户强需求 + 京东弱 + 竞品已验证有效 → 最该补
- ★★ = 用户中需求,或竞品也没做透(蓝海)
- ★ = 用户弱需求,或京东其实已够用

**避坑**:Gap 不是"竞品有而我没有"。竞品有但用户不需要的,不是 Gap 是噪音。**必须三列一起看**。

### Step 2 · 提炼差异化定位(30 分钟)

京东在这个品类应该是"谁"?用**排除法**逼出定位:

```
京东在本品类【不该是】:______(如"低价卖场"——拼多多已占)
京东在本品类【不该是】:______(如"内容社区"——小红书已占)
京东在本品类【应该是】:______(如"决策辅助专家"——货全+自营+物流可信)
```

定位要**接住京东的固有优势**(自营、物流、正品、会员),而不是硬追竞品的长板。

**定位要站在平台价值观上**。京东零售的 4 条设计价值观是定位的地基,固有优势天然对应其中两条:

| 价值观 | 对应的京东优势 | 定位可以怎么长 |
|---|---|---|
| **务实**(投入产出/专业可靠) | 自营、正品、物流时效 | "可信赖的决策专家",而非"最低价" |
| **自然**(商业与用户价值平衡) | 会员体系、复购心智 | 长期陪伴而非一次性收割 |
| **包容**(多元兼容) | 品类全、SKU 广 | 覆盖多元人群与场景,而非单一爆款 |
| **焕新**(主动进化) | 技术投入、供应链 | 用新技术/新范式重塑体验 |

> 提炼定位后问一句:**"这个定位站在哪条价值观上?"** 答不上来,说明是口号不是定位。见 `参考资料/京东设计哲学(平台基线).md` 第二节。

一句话定位模板:
> "京东{品类}应是'{独特身份}',而非'{竞品甲的定位}'或'{竞品乙的定位}'。"

**避坑**:定位不是口号。"做最好的{品类}平台"不是定位。定位必须**排他**——说清你不做什么,才叫定位。

### Step 3 · 生成机会清单(30 分钟)

Gap 矩阵里每个 ★★ 以上的空白,翻译成 1-N 个具体机会。机会要**可执行、可指认到模块**:

- ✅ 好机会:"榜单页重构:按场景分榜 + 加'值得买'理由标签"
- ❌ 坏机会:"提升用户体验"(不可执行)/"做内容"(太泛)

轻档挑 3 个,中档 5-7 个,重档不限但每个要有规模测算。

### Step 4 · 机会四维打分(30 分钟)

用固定四维给每个机会打分(3=高/2=中/1=低),排出优先级:

```markdown
| 机会 | 用户价值 | 差异化 | 落地难度 | KPI 支撑 | 总分 | 优先级 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| 榜单信息重构 | 3 | 3 | 2 | 3 | 11 | 短 |
| 书评/评测体系 | 3 | 3 | 1 | 2 | 9 | 中 |
| AI 导购 | 2 | 3 | 1 | 1 | 7 | 长 |
```

四维定义:
- **用户价值**:解决的痛点有多痛、覆盖多少用户
- **差异化**:是否强化定位、竞品是否难跟
- **落地难度**:⚠**反向计分**——3=容易落地,1=很难(这样总分越高越该先做)
- **KPI 支撑**:能否明确关联业务指标、见效是否可衡量

**总分不是唯一裁判**:高分但依赖新技术的,仍归长期;低分但零成本的,可插进短期。打分是**辅助排序**,不是自动决策。

### Step 5 · 落成三档优先级(30 分钟)

用 `模板/优先级表-三档分期.md`,把机会按时间价值分档。**三档要有故事线**:

```
短期(1-2 月)· 解决"最痛的问题" —— 视觉/信息重构,单动作 <10 人日
   ↓ 承接
中期(3-6 月)· 建立"结构性优势" —— 新模块开发,20-60 人日
   ↓ 兜住
长期(6 月+)· 瞄准"未来 3 年位置" —— 战略级,需新技术/跨端
```

每档 2-4 条,**每条必带主指标**(哪怕是假设值)。分档判断标准详见模板。

**避坑**:别把所有机会都堆短期。全短期 = 只是 wishlist,不是规划。短/中/长应大致均衡(如 3+3+2)。

## AI 辅助 prompt 示例

### 帮我搭 Gap 矩阵

```
我在做京东「{品类}」的机会分析。三方信息如下:

用户诉求(来自痛点分析):
- {诉求 1}、{诉求 2}...

京东现状(来自内诊):
- {现状 1}...

竞品供给(来自竞品分析 ④体验对比 / ⑤心智象限):
- {竞品做法 1}...

请搭一个 Gap 矩阵:每行一个用户诉求,列出京东现状 vs 竞品供给,
标 Gap 等级(★★★=强需求+京东弱+竞品验证有效;★★=中需求或蓝海;★=弱需求或京东已够)。
提醒:竞品有但用户不需要的,不算 Gap。
```

### 帮我逼出差异化定位

```
京东在「{品类}」有这些固有优势:{自营/物流/正品/会员...}。
主要竞品的定位:
- {竞品 A}:{定位}
- {竞品 B}:{定位}

请用排除法帮我提炼京东的差异化定位:
先说京东"不该是"什么(竞品已占的),再说"应该是"什么(接住京东优势的)。
并**指明这个定位站在京东哪条设计价值观上**(务实/自然/包容/焕新)。
给出一句话定位,句式:"京东{品类}应是 X,而非 Y 或 Z。"
```

### 帮我给机会打分排序

```
以下是候选机会清单:
{列出机会}

请用四维打分(3=高/2=中/1=低),注意落地难度反向计分(3=容易落地):
用户价值 / 差异化 / 落地难度 / KPI支撑。
给出总分表和建议优先级(短/中/长)。
但请额外提醒:哪些机会总分高却因依赖新技术应归长期,
哪些总分低却因零成本可插进短期。
```

### 帮我编排三档故事线

```
以下是打过分的机会:
{粘贴打分表}

请分成短(1-2月)/中(3-6月)/长(6月+)三档,每档 2-3 条,要求:
- 有故事线:短期解决最痛的,中期建结构优势,长期占未来
- 每档投入量级递增(短<10人日 / 中20-60 / 长不设限)
- 每条带一个主指标(可以是假设值,但要具体到数字或行为)
- 三档条数大致均衡,不要全堆短期
```

### Step 6 · 设计师行动方案纵深链(⭐ 中/重档必做,决定报告"能不能用")

> **为什么必做**:机会清单和三档优先级是给"决策层"看的(该不该做);但拿报告去执行的是**频道设计师**,他们的问题是"这条机会我具体怎么动手?"。如果每条机会只有一句话("签到玩法图书化"),设计师会说"不知道能用这报告解决什么"。**所以每条 P0/短期机会必须展开成一条"照着能开工"的纵深链。**

**每条重点机会(至少覆盖全部短期档 P0)展开六段纵深链:**

```
① 目标 —— 扣住哪个业务指标(DAU/转化/复访…)
② 现状问题 —— 以真实截图为证,具体到哪个页面哪里不对(不是泛泛"体验差")
③ 竞品参考 —— 谁做得好、好在哪(接阶段2竞品模块级拆解)
④ 设计动作 —— ⭐核心:具体到设计师能开工。机制怎么改、视觉用什么、动效什么隐喻,
   配一张灰阶低保真线框图(见下方规范)。禁止写"提升体验"这类空话。
⑤ 落地资产 —— 映射到品类差异资产(阶段7)的哪几段(④玩法/③图形/⑥动效…)
⑥ 怎么衡量 —— 成功指标(可假设,但要具体到指标/行为)
```

**④设计动作的灰阶低保真线框图(硬要求)**:
- 每条行动方案配**一张**单页线框图(非流程图),用手机框示意关键界面布局;
- **灰阶**:深灰=按钮/强调,中灰=图片/模块占位,浅灰=文字占位;
- 标注"灰阶示意,落地配色见资产库色板"——线框图聚焦布局,不聚焦配色;
- 目的:比 ASCII 文字框"显象",设计师一眼看懂布局意图。渲染规范见 `阶段说明/阶段8-报告装配与自检.md`。

**判断标准**:写完④设计动作,问自己"设计师照着这段,能不能直接开工画稿?"——不能,就是还没写透。

## 三档差异

| 项 | 轻档 | 中档 | 重档 |
|---|---|---|---|
| 机会数 | 3 个 | 5-7 个 | 不限,每个含规模测算 |
| Gap 矩阵 | 简版(3 行) | 完整(5-6 行) | 完整+量化 Gap |
| 打分 | 可省,凭判断排序 | 四维打分 | 四维打分+规模测算 |

## 自检清单

- [ ] Gap 矩阵三列齐全(用户诉求/京东现状/竞品供给),不是"竞品有我没有"清单
- [ ] Gap 等级有区分,不是全 ★★★
- [ ] 差异化定位是**排他**的(说清不做什么)
- [ ] **定位指明了所站的平台价值观**(务实/自然/包容/焕新之一)
- [ ] 定位接住了京东固有优势,不是硬追竞品
- [ ] 每个机会可执行、可指认到模块(不是"提升体验")
- [ ] 机会做了四维打分(落地难度记得反向)
- [ ] 有短/中/长三档,每档至少 2 条
- [ ] 每个动作带主指标(哪怕假设值)
- [ ] 三档有故事线,不是三张不相关清单
- [ ] 推导只用了阶段 4 验过的结论,没用存疑数据
- [ ] **⭐(中/重档)重点机会展开了六段纵深链**(目标→现状问题→竞品参考→设计动作→落地资产→衡量)
- [ ] **⭐ 每条设计动作配了灰阶低保真线框图**,且具体到"设计师照着能开工"(不是"提升体验")
- [ ] 行动方案的落地资产映射到了品类差异资产(阶段7)对应段

## 常见坑

- **坑 1**:Gap 写成"竞品有而京东没有" → **必须叠加"用户是否需要"**,否则是抄竞品,不是补空白。
- **坑 2**:差异化定位写成口号("做最好的平台")→ **定位必须排他**,说清不做什么。
- **坑 3**:机会太泛("做内容""提升体验")→ **必须可执行、可指认到具体模块**。
- **坑 4**:落地难度正向计分,导致"难做的"排前面 → **落地难度反向**:容易落地得高分。
- **坑 5**:所有机会都塞短期 → **全短期=wishlist**。短中长要均衡,有故事线。
- **坑 6**:机会/优先级停在"一句话",没展开行动方案 → 设计师会说"不知道能用这报告干嘛"。**中/重档必须展开六段纵深链 + 线框图**,让报告从"分析"落到"能开工"。
- **坑 6**:动作不带指标 → 阶段 8 的 KPI 假设就是从这些指标来的,现在不写后面接不上。
- **坑 7**:拿存疑数据做推导 → **只用阶段 4 验过的**,流沙上盖不起楼。
