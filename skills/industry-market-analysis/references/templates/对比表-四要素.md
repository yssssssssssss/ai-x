# 四要素对比表

> 用于阶段 2(竞品拆解)、阶段 6(视觉方向对比)。四要素固定不变:核心特征 / 适配场景 / 优点 / 局限。

## 用法

复制粘贴到你的报告或分析文档里,替换占位符即可。

## 单项模板(竞品/方向)

```markdown
### {名字}

| 维度 | 内容 |
|---|---|
| 核心特征 | {它最不一样的地方,1-2 句} |
| 适配场景 | {用户什么时候来用,高频/低频,买货/看内容} |
| 优点 | 1. {优点 1,具体} <br> 2. {优点 2} <br> 3. {优点 3} |
| 局限 | 1. {局限 1,具体} <br> 2. {局限 2} |
```

## 多项对比模板(横向比较)

```markdown
| 项目 | 核心特征 | 适配场景 | 优点 | 局限 |
|---|---|---|---|---|
| 竞品 A | ... | ... | ... | ... |
| 竞品 B | ... | ... | ... | ... |
| 竞品 C | ... | ... | ... | ... |
```

## 视觉方向对比模板

```markdown
### 视觉方向对比

| 方向 | 核心特征 | 适配场景 | 优点 | 局限 |
|---|---|---|---|---|
| A · {风格名} | 主色调 / 排版感 / 图像风格 | 什么样的用户/场景适合 | 3 点具体的优势 | 2 点具体的挑战 |
| B · {风格名} | ... | ... | ... | ... |
| C · {风格名} | ... | ... | ... | ... |
| D · {风格名} | ... | ... | ... | ... |
```

## 写作要点

### 核心特征

- **是什么**:一句话说清最不一样的地方
- **不是**:通用描述(如"体验好")、宽泛定位(如"综合电商")
- **好例子**:"通过评论和评分构建决策辅助,而非单纯展示 SKU"
- **坏例子**:"体验完善,内容丰富"

### 适配场景

- **是什么**:说清用户为什么来、什么时候来、来一次多久
- **好例子**:"用户在决策阶段(下单前 3-5 天)反复访问,单次停留 8-12 分钟"
- **坏例子**:"适合所有购物用户"

### 优点(3 条具体的)

- **是什么**:具体到"哪个功能/交互/视觉如何解决了什么问题"
- **好例子**:"详情页把评论的'差评'和'好评'分开展示,帮用户预判风险"
- **坏例子**:"评论体系完善"

### 局限(2 条具体的)

- **是什么**:不要粉饰,不要通用,要指向具体缺陷
- **好例子**:"缺少视频评价,导致高单价商品的信任建立慢"
- **坏例子**:"体验一般,还有提升空间"

## 常见误区

- **误区 1**:每项都写 5-6 条 → 应精选 3 条优点 + 2 条局限。多则不精。
- **误区 2**:局限用套话 → 局限比优点更能显示分析深度。**要具体到功能层面**。
- **误区 3**:所有对象套一模一样的话术 → 每个对象的独特之处才是价值。避免"模板复读机"。
- **误区 4**:核心特征写成"公司介绍" → 核心特征是"和其他家最不一样的一点",不是完整定位。

## 例子:图书报告中的 4 要素样例(节选自图书行业已完成的报告)

```markdown
### 微信读书

| 维度 | 内容 |
|---|---|
| 核心特征 | 免费阅读+社区书评+内容沉浸式,弱化"购买"心智 |
| 适配场景 | 用户在通勤/睡前的碎片时间打开,单次 15-30 分钟 |
| 优点 | 1. 书架式界面,视觉沉浸感强 <br> 2. 免费机制降低决策门槛 <br> 3. 书友书评比传统电商更真实 |
| 局限 | 1. 电子书为主,不覆盖纸质书购买 <br> 2. 编辑推荐弱于自然发现 |
```

好的 4 要素表能让读者不用打开竞品 App 就理解竞品的定位。
