# Web 工作台

## 目的

为用户提供登录、任务创建、候选计划选择、媒体上传、执行进度、报告查看和历史复盘界面。

## 模块概述

- **职责:** 调用 Agent API、解析 POST SSE、显示计划和执行阶段、展示 V2 报告与反馈操作。
- **状态:** ✅稳定。
- **最后更新:** 2026-07-22

## 规范

### 需求: 用户确认后才执行
**模块:** Web 工作台

用户必须选择候选计划，并在所需媒体上传完成后才能提交执行。

#### 场景: 计划要求设计稿
- 界面展示角色、数量和 MIME 限制。
- 缺少必传材料时禁用确认操作，并能展示后端 `422` 作为最终保护。
- 客户端保留 API 返回的错误码，便于区分补充材料、状态冲突与上游故障。

### 需求: 报告证据语义可见
**模块:** Web 工作台

用户应能区分证据事实、算法或模拟信号、模型推断及待确认风险。

#### 场景: 部分工具失败
- 展示已完成步骤与缺口。
- 报告的风险与待确认项不被呈现为已验证结论。
